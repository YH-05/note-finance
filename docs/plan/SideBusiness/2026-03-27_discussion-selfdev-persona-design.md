## 決定事項

### dec-2026-03-27-selfdev-pd001
**アカウント名: 「玄人領域｜静かに強くなる思考の技術」**

- 「玄人（くろうと）」の知的な響き + 「領域」のparanoia感（「本質領域へ」）
- 完全オリジナル造語。検索してもこのアカウントしか出ない
- 特定の偉人・思想に縛られず、4本柱の幅広いテーマと矛盾しない
- サブタイトル「静かに強くなる思考の技術」= フォローする理由が即伝わる
- 検討経緯: 第一原理思考（既存）→ 原点思考（既存）→ 韓非思考（人物に縛られる）→ 玄人領域
- ユーザーネーム: @kuroto_area

### dec-2026-03-27-selfdev-pd002
**bio（自己紹介文）確定 — プラットフォーム別**

**Threads用（集客向け）:**
```
フォローすると毎日5つ、思考の武器が増えます。
考え方が変われば、行動は勝手に変わる。

▶ 習慣 / 意思決定 / 集中力 / 自己設計
▶ 内向型のための思考アカウント
▶ note → [link]
```

**note用（深掘り向け）:**
```
読むたびに、思考の精度が上がる。
一つずつ積み上げた思考の型が、静かに人生を変えていく。

▶ 習慣 / 意思決定 / 集中力 / 自己設計
▶ 内向型のための思考アカウント
▶ Threads → @kuroto_area
```

設計方針:
- 冒頭2行で「フォローするとどんな得があるか」を明示
- ソース（ストア派/行動科学等）は明示しない（手札を見せない）
- Threads = 即時的メリット訴求、note = 積み上げ型の価値訴求
- 箇条書きで扱うテーマを一覧
- 相互導線を最下部に配置

### dec-2026-03-27-selfdev-pd003
**語り口: 「です・ます」調に確定**

- 丁寧だが距離感がある文体
- 内向哲学(yuma)に近いスタイル
- 煽らない・急かさないトーンと一致

### dec-2026-03-27-selfdev-pd004
**ビジュアルトーン: アーストーン・自然系**

| 要素 | 内容 |
|------|------|
| 配色 | ベージュ / カーキ / オリーブ |
| アイコン | 石や木のテクスチャ |
| 世界観 | 禅・ワビサビ的。自然素材の質感 |
| フォント感 | セリフ系。落ち着いた知的さ |
