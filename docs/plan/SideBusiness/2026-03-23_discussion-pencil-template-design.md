# 議論メモ: career_sister Instagram カルーセルテンプレート設計方針

**日付**: 2026-03-23
**参加**: ユーザー + AI
**Neo4j Discussion ID**: disc-2026-03-23-pencil-template-design

## 背景・コンテキスト

Threads×Instagram自動投稿マネタイズ戦略のcareer_sisterアカウントについて、Instagram カルーセル投稿用のPencilテンプレート設計方針を議論。前提として以下が決定済み:
- ツールチェーン: pencil.dev + Playwright + Instagram Graph API（disc-2026-03-21-instagram-expansion）
- 投稿形式: カルーセル（スライド形式）（dec-2026-03-21-instagram-post-format）
- ペルソナ: キャリアお姉さん（姉御肌×大手→ベンチャー）（dec-2026-03-23-career-sister-persona）

## 議論のサマリー

### Q1: ビジュアルトーン
- 4案を比較: ウォームプロ / クールモダン / ポップカジュアル / ナチュラルアース
- **決定**: ウォームプロ（暖色系×モダンレイアウト）
- 理由: 姉御肌の「頼れる先輩」感を表現。暖かみと信頼感の両立

### Q2: スライド枚数
- 3案を比較: 5枚 / 7枚 / 10枚 / 型別可変
- **決定**: 7枚構成（表紙+本文5+CTA）
- 理由: 情報量と滑りのバランスが良い。転職系Instagramで最も一般的

### Q3: テンプレートバリエーション
- 3案を比較: 共通1テンプレ / 型別に色違い / 型別に全く別デザイン
- **決定**: 型別に色違い（レイアウト共通）
- 理由: フィードの統一感を維持しつつ単調にならない。カテゴリ識別も可能

### Q4: フォント
- 3案を比較: 丸ゴシック系 / ゴシック系 / 明朝体ミックス
- **決定**: 丸ゴシック系（見出しBold / 本文Regular）
- 理由: 姉御肌の「タメ口」トーンと相性が良い。親しみやすく読みやすい

### Q5: 表紙レイアウト
- 3案を比較: テキスト中心 / テキスト+アイコン / 上下分割型
- **決定**: 上下分割型（上半分:アクセントカラーベタ塗り、下半分:テキスト）
- 理由: フィードでのメリハリが強く、スワイプを止めるフック効果が高い

## 決定事項

1. **dec-2026-03-23-carousel-visual-tone**: ウォームプロ（Warm Professional）トーンを採用
2. **dec-2026-03-23-carousel-color-by-type**: 型別色違い（レイアウト共通）
3. **dec-2026-03-23-carousel-slide-structure**: 7枚構成、上下分割型表紙、丸ゴシック系フォント
