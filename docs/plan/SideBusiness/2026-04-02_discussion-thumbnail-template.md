# 議論メモ: 株投資ラボ noteサムネイルテンプレート作成

**日付**: 2026-04-02
**参加**: ユーザー + AI

## 背景・コンテキスト

株投資ラボとしてnote.comに投稿している記事のサムネイル（見出し画像）にテンプレートが必要。
Pencil（.penファイル）を使い、MCP経由でClaude Codeから直接デザインを作成した。

## 議論のサマリー

### Phase 1: 初期テンプレート作成
- 1280x670px（note.com推奨サイズ）で5カテゴリ分を作成
- ダークグラデーション背景 + 幾何学アクセント + カテゴリカラー

### Phase 2: ベストプラクティス調査・改善
- note.comサムネイルのベストプラクティスを調査
- 主要な発見:
  - テキストは10文字以内、メッセージ1つに絞る
  - フォントサイズ48px以上（推奨70-90px）、太ゴシック
  - 重要要素は画像中央60%のセーフゾーン内
  - スマホタイムラインでは元画像の約1/4に縮小表示
  - note記事タイトルはサムネイル下に自動表示されるため、サムネ内にフルタイトル不要
- 改善: フォント52px→80px、テキスト3行→2行（10文字以内）、サブタイトル削除

### Phase 3: レイアウト変更
- ユーザー要望: カテゴリカラー帯を横一直線に + テーマ別背景画像
- 背景にUnsplash画像を各カテゴリに適用
- ダークオーバーレイ（最終: 30%）で画像を透過表示
- 帯を上部に配置、カテゴリバッジを右下に移動

## 決定事項

1. **ツール選定**: Pencil（.penファイル）でMCP経由作成
2. **カテゴリ別カラーコード**:
   - マクロ経済: 青 `#3B82F6`（アイコン: trending-up）
   - 個別株分析: 赤 `#EF4444`（アイコン: activity）
   - 資産形成: 緑 `#10B981`（アイコン: wallet）
   - 金融教育: アンバー `#F59E0B`（アイコン: book-open）
   - 週次レポート: パープル `#8B5CF6`（アイコン: file-text）
3. **デザイン仕様**:
   - サイズ: 1280x670px
   - タイトル: 80px / weight 800 / Inter
   - カテゴリカラー帯: 上部横断配置（height 210px）
   - 背景: テーマ別Unsplash画像 + 30%ダークオーバーレイ
   - カテゴリバッジ: 右下
   - ブランドマーク「株投資ラボ」: 左下
4. **保存先**: `articles/templates/kabushiki-labo-thumbnails.pen`
