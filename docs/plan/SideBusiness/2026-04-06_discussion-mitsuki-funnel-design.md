# 議論メモ: みつき導線設計 — メンバーシップ×ココナラ ハイブリッド型連携

**日付**: 2026-04-06
**参加**: ユーザー + AI

## 背景・コンテキスト

みつきの収益化戦略は4/2-4/3の競合分析・ココナラ市場調査で固まっている。
本議論はThreads→note→メンバーシップ/ココナラの**導線設計**、特に
メンバーシップとココナラの連携方法を具体化するもの。

### 前提（既決事項）
- ポジション: 「タロット×心理学×自己理解ガイド」（市場でほぼ未開拓）
- 収益化モデル: 無料記事多投稿→メンバーシップ誘導
- メンバーシップ: ¥500/月、居場所型
- ココナラ: フロント¥1,000 / ミドル¥3-4k / バックエンド¥5-12k
- 現状: Threads 45投稿、note 9記事（あと1本でメンバーシップ開設ライン）

## 議論のサマリー

### 1. 連携モデルの選定

3つのモデルを比較検討:

| モデル | 概要 | 判定 |
|--------|------|------|
| 階段型 | メンバー→ココナラへ一方向アップセル | △ 逆流がない |
| 並列型 | 独立した2収益源、相互送客なし | × シナジーなし |
| **ハイブリッド型** | コンテンツ特典で紐づけ+双方向送客 | **採用** |

### 2. 特典タイプの選定

| タイプ | 概要 | 判定 |
|--------|------|------|
| 割引・優先型 | ココナラ10%OFF、優先予約枠 | × 情報商材感のリスク |
| **コンテンツ型** | 深掘りコンテンツが自然にココナラ導線に | **採用** |
| ミックス型 | コンテンツ主軸+さりげなく優先枠 | △ 運用複雑 |

**理由**: みつきの「居場所型」「詩的文体」「心理的安全性」コンセプトと整合するのはコンテンツ型。

### 3. メンバー限定コンテンツ構成（月12本・週3本）

#### 週次固定スケジュール

| 曜日 | コンテンツ | → ココナラ導線先 |
|------|----------|----------------|
| 月 | タロット深掘り（大/小アルカナ詳細+自己理解ワーク） | → 個別鑑定 ¥1,000 |
| 水 | 心理学Tips深掘り（Eurich式/認知パターン/愛着理論等） | → PDF鑑定書 ¥3-4k |
| 金 | 星座リーディング（週間メッセージ+心理学的背景） | → PDF鑑定書 ¥3-4k |

#### 月次特別版（週次枠内で差し替え）

| 週 | 差し替え | 内容 | CTA |
|----|---------|------|-----|
| 第1金曜 | 星座→月間テーマ | 12星座の月間メッセージ+心理学テーマ | 強めCTA |
| 第2水曜 | Tips→セルフケアワークシート | ジャーナリングプロンプト+振り返りガイド | 強めCTA |
| 第3月曜 | タロット→みつきの本音コラム | 共感・つながり系コンテンツ | **CTAなし** |
| 第4水曜 | Tips→月間振り返り&来月プレビュー | 継続動機の強化 | **CTAなし** |

**CTA配分**: 12本中 CTA付き10本(83%) / CTAなし2本(17%)

### 4. 逆流導線（ココナラ→メンバーシップ）

両面で実施:
- **商品内埋め込み**: PDF鑑定書最終ページ、テキスト鑑定結果末尾に自然な案内
- **購入後メッセージ**: お礼+「継続的な自己理解の旅には→noteメンバーシップ」

## 決定事項

1. **ハイブリッド型連携**: メンバーシップとココナラをコンテンツ型特典で紐づけ、双方向送客
2. **月12本限定コンテンツ**: 週3本（月タロット/水Tips/金星座）+月次特別4本差し替え
3. **逆流導線は両面**: 商品内埋め込み+購入後お礼メッセージ

## 全体導線フロー

```
Threads（認知・週35投稿）
  │ 週4回note誘導（月水金日22:00）+ プロフィールリンク
  ▼
note無料記事（信頼構築）
  ├─→ メンバーシップ ¥500/月（居場所型）
  │     月12本限定記事（週3: 月タロット/水Tips/金星座）
  │     うち10本にココナラCTA → ココナラへ順方向送客
  │     うち2本CTAなし（本音コラム・月間振り返り）
  │
  └─→ ココナラ（個別収益化）
        フロント ¥1,000 / ミドル ¥3-4k / バックエンド ¥5-12k
        商品内+お礼MSG → メンバーシップへ逆流送客
```
