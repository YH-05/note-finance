## 決定事項

### dec-2026-03-27-spi-divination-three-pillars
**占術3本柱をタロット（SNS週次）×星座（SNS定期）×数秘術（note有料）に確定**

テキスト制約のもとで各占術の強みを役割分担。

| 占術 | 役割 | 投稿形式 | 理由 |
|------|------|---------|------|
| **タロット** | SNS週次テーマ設定・神秘的な入口 | 週次1枚引き+心理学テキスト解説 | 画像なしでも週次テーマとして機能。神秘性でエンゲージメント高い |
| **星座** | SNS定期・自己同一化の広い入口 | 星座別テキスト（12種） | 全員が自分の星座を知っている。自己同一化★★★★ |
| **数秘術** | note有料プロダクト収益エンジン | 生年月日入力→AI自動生成 | AI自動化★★★。パーソナライズ可能。1回完結 |

**投稿カレンダー方針**:
- 週1-2回: タロット（月曜 or 水曜が最適）
- 週1-2回: 星座（金曜 or 日曜）
- 随時（SNS誘導から）: 数秘術 → note有料記事

### dec-2026-03-27-spi-product-dual-launch
**note有料プロダクトを鑑定書（¥500-1,000）＋ガイドブック（¥2,000-3,000）の同時ローンチで展開**

ラインナップアンカリング効果を狙い同時ローンチを選択。

| プロダクト | 内容 | 価格 | 顧客特性 |
|-----------|------|------|---------|
| **数秘術 自己理解鑑定書** | 誕生数別×5章（性格・強み・課題・コミュニケーション・キャリア）。受動的：あなたについての解説 | ¥500-¥1,000 | 入門者・低コミット・まず試したい |
| **数秘術 自己探求ガイドブック** | 鑑定書5章＋ジャーナリングプロンプト20問＋Eurich式自己認識ワーク＋核心層心理学解説。能動的：あなたが実践するツール | ¥2,000-¥3,000 | Type B内的探究型・本気組 |

**YUKI踏襲＋差別化**:
- YUKI事例の鑑定書起点モデルを踏襲（¥500〜低ハードル）
- 同時にガイドブック（高価値版）を提示してアンカリング効果
- Type B内的探究型には「使うもの」であるガイドブックがより刺さる

## テキスト占術コンテンツの実装パターン

### タロット（テキスト形式）

```
パターン1 - 週次一枚引き:
「今週のカード：隠者（The Hermit）
内省の力と認知的孤独 ─ なぜ「ひとりの時間」が本当の自分を見つけるのか

隠者は灯台を持ち、暗闇を照らしながら歩む...（Eurich自己認識研究への橋渡し）」

パターン2 - Pick-a-Card（テキスト版）:
「A/B/C から直感で選んでください
→ A選んだ人: 塔のカード（変容・手放し）...
→ B選んだ人: 月のカード（無意識・直感）...
→ C選んだ人: 星のカード（希望・再生）...」
```

### 星座（テキスト形式）

```
パターン - 星座×心理学:
「天秤座が本当に求めているもの（愛着理論×均衡欲求）
─ なぜ天秤座は「どちらでもいい」と言いながら葛藤するのか」
```

### 数秘術（有料記事・AI自動生成）

```
入力: 生年月日（例：1990年5月15日）
生命数計算: 1+9+9+0+5+1+5 = 30 → 3+0 = 3

出力（鑑定書）:
第1章: 誕生数3のあなたの性格プロファイル
第2章: 強みと才能（社会的比較理論との関連）
第3章: 課題とパターン（認知バイアスの視点から）
第4章: コミュニケーションスタイル
第5章: キャリアと使命

出力（ガイドブック追加部分）:
第6章: 20のジャーナリングプロンプト
第7章: Eurich式「What問い」セルフ発見ワーク
第8章: 誕生数3の心理学的根拠
```
