# 議論メモ: みつきD型プロダクト占術戦略 — 占術選定・ブランド一貫性設計

**日付**: 2026-04-07
**参加**: ユーザー + AI

## 背景・コンテキスト

みつきのD型プロダクト（AI生成パーソナル分析PDF、ココナラ ¥1,500/テーマ）に最適な占術を選定する議論。
現行は数秘術（生年月日→LP等）+ タロット + 星座の3本柱だが、D型プロダクトとしては星座（12パターン）の深みが不足。
占術を追加する一方で、ブランドの一貫性をどう保つかが核心論点。

## 議論のサマリー

### 1. D型プロダクト適性の占術評価

各占術をD型の5条件（決定論的入力・変数空間・心理学クロス・コレクション誘発・自動化容易性）で評価。

| Tier | 占術 | 判定 |
|------|------|------|
| S | 数秘術 | 採用済み。D型の中核 |
| A | 惑星星座（出生図の生年月日版） | 追加推奨 |
| A | MBTI | 採用決定（パターンA） |
| A | エニアグラム | 検討継続 |
| B | 四柱推命 | 見送り |
| C | タロット・ルーン・手相等 | D型非推奨 |

### 2. 惑星星座の発見

出生図フル（出生時刻+場所必要）はインプットが重すぎる。しかし**生年月日だけ**でSun/Venus/Mars/Mercury/Jupiter/Saturnの6惑星星座が確定する。

- Sun × Venus × Mars だけで 12×12×12 = 1,728パターン
- 入力は数秘術と全く同じ（生年月日の8桁）
- 4テーマに惑星が1対1対応: 恋愛=Venus、仕事=Mars、人間関係=Mercury、ストレス=Saturn

### 3. MBTIの入力問題と解決

ココナラ占い購入フローでMBTI診断を必須にすると離脱要因になる。
→ パターンA（任意入力）で解決: 「MBTIタイプをご存知の方は教えてください」
→ 知ってる人にはボーナスセクション、知らない人でも数秘×惑星星座で十分成立

### 4. 四柱推命の見送り

D型適性自体は高い（生年月日で3柱確定、変数空間広大）が、以下の理由で見送り:
- パステル×心理学ブランドと東洋占術の世界観が衝突
- 五行と心理学のクロス分析が不自然
- ココナラ四柱推命市場はレッドオーシャン

### 5. ブランド一貫性問題と解決（最重要決定）

占術が複数あると「占いの幕の内弁当」になる問題。
→ 解決策: **占術を減らすのではなく、見えなくする**

- ブランドメッセージ: 「生年月日で、自分のパターンを読み解く」
- D型PDFでは占術名を出さない。ユーザーが見るのは「あなたは○○タイプ」という統合結果のみ
- 数秘・惑星星座・MBTI・心理学は裏側エンジン
- Threadsではタロット・星座を集客フック（#タロット #蟹座）として引き続き使用

## 決定事項

1. **MBTIパターンA採用**: 任意入力。ボーナスセクション方式。必須入力にしない
2. **惑星星座追加**: 生年月日のみでSun/Venus/Mars/Mercury/Jupiter/Saturn計算。D型エンジンに追加
3. **四柱推命見送り**: ブランド不一致。空白市場（数秘×惑星星座×心理学）で戦う
4. **占術を裏側に隠す**: ブランドメッセージ「生年月日で自分のパターンを読み解く」。占術名はD型の表面に出さない
5. **星座の役割限定**: Threads集客フック専用。D型の星座分析は惑星星座が担う

### D型インプット設計（確定）

```
必須入力（生年月日のみ）:
  → 数秘術: LP, Expression, Soul Urge, Personal Year
  → 惑星星座: Sun, Venus, Mars, Mercury, Jupiter, Saturn
  → 12星座: Sun sign（集客フック用に残す）

任意入力:
  → MBTI: 16型（知ってる人だけ → ボーナスセクション）
  → 出生時刻: Moon星座の精度UP（知ってる人だけ → 追加分析）
```

### D型プロダクト出力イメージ（確定）

占術名を出さず「○○タイプ」として統合出力:
```
「あなたは"つながり渇望タイプ"です。
 楽しい場の中心にいるのに、ふと不安になる...」

（裏側: LP3の社交性 × 金星蟹座の安全基地欲求 × 不安型愛着）
```
