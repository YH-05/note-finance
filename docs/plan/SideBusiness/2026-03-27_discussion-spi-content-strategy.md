## 決定事項

### dec-2026-03-27-spi-positioning
**スピ系アカウントのポジショニングを「自分を知るためのガイド」に確定**

占い師・霊能者ではなく、自己探究のサポーターとして設計。Z世代の占い利用は「信じる/信じない」の二項対立ではなく、自己表現・コミュニケーション・エンタメ・意思決定支援の手段として機能している（PR TIMES調査）。

### dec-2026-03-27-spi-persona-type-b
**Type B（内的探究型）ペルソナに特化**

- Type A（外的承認型）: 恋愛・運勢判断・他者評価目的 → 競合過多のレッドオーシャン
- Type B（内的探究型）: 自己理解・パターン認識・変化への許可 → 供給が薄いブルーオーシャン

r/tarotコミュニティデータでも、視聴者の自己成長志向の需要が供給を大幅に上回っている。

### dec-2026-03-27-spi-two-layer-model
**コンテンツを3層で設計**

```
入口層（占い・スピ）
  ├ 目的: 心理的ハードル低下・感情的アクセスしやすさ・SNS拡散性
  └ 例: 週間タロット、月の満ち欠け、数秘術基礎、今日のカード

橋渡し層（翻訳コンテンツ）
  ├ 目的: 占い言語 → 心理学言語への変換
  └ 例: 「タロット塔のカードが教える認知的再評価の力」

核心層（エビデンスベース心理学）
  ├ 目的: 再現性のある自己成長メソッド・有料コンテンツの核心
  └ 例: Tasha Eurich自己認識ワーク、認知的再評価シート、ジャーナリング
```

**投稿比率: 入口2 : 橋渡し2 : 核心3**

**競合マッピング**:
- 純粋な占いアカウント: 温かい×非科学的（レッドオーシャン）
- 純粋な自己啓発アカウント: 冷たい×科学的（発見可能性低）
- **このアカウント**: 温かい×科学的（現在ほぼ空白地帯）

### dec-2026-03-27-spi-numerology-priority
**占い入口機能として数秘術を優先検討**

| 占術 | SNS拡散性 | AI自動化 | 心理学接続 | 習得コスト |
|------|----------|---------|---------|---------|
| 数秘術 | 中 | ★★★ | ★★★（数字=統計） | 低 |
| タロット | ★★★ | 中 | 中 | 高 |
| 占星術 | ★★★ | 中 | 中 | 高（CAGR 24.76%） |

数秘術は生年月日のみでパーソナライズ可能・AI自動生成適合・数字という統計的メタファーとして核心層への橋渡しが自然。
