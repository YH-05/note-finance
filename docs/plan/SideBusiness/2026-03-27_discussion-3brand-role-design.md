## 決定事項

### dec-2026-03-27-split-axis
**スピ系とself-devの分割軸を「感じる自己理解 vs 考える自己設計」に確定**

| 軸 | スピ系 | self-dev |
|---|---|---|
| 認知モード | 感じる（直感・感覚・象徴） | 考える（論理・分析・実験） |
| 問い | "What am I feeling?" | "How am I thinking?" |
| 内省のスタイル | 感情・直感と向き合う | 思考パターン・行動を分析する |
| 入口 | 占い・タロット・数秘術 | 哲学・ストア派・思考実験 |
| 核心 | 心理学ベース自己認識ワーク | フレームワークベース自己設計 |
| トーン | 温かい・受容的・柔らかい | 静謐・淡々・本質的 |
| ターゲット | 主に女性・自己理解志向 | 主に男性・内向型 |

「内省」の重複問題は認知モードで解消:
- スピ系の内省 = ジャーナリングで感情を言語化する（Eurich式）
- self-devの内省 = メンタルモデルで思考の盲点を分析する（エピクテトス制御二分法）

### dec-2026-03-27-selfdev-concept
**self-devアカウントのコンセプトを「静かな自己改造」に確定**

煽らない。急かさない。論理と哲学で、淡々と自分を設計し直す。

**コンテンツ4本柱**:
1. **哲学的基盤** — ストア派・禅・エピクテトスの制御二分法
2. **海外メソッド翻訳** — paranoia式の海外自己啓発コンテンツの日本語再解釈
3. **内向型戦略** — 内向哲学式の「静かに強くなる」方法論
4. **思考フレームワーク** — メンタルモデル、認知バイアス、意思決定最適化

**ターゲットペルソナ**:
- 20-30代男性（内向型）
- 外向的な自己啓発に疲れている
- SNSの煽り系インフルエンサーに辟易
- 哲学・論理ベースで静かに自分を変えたい

### dec-2026-03-27-selfdev-revenue
**self-devアカウントの収益モデルをハイブリッド型に確定**

- 主軸: noteメンバーシップ（月額¥500-1000、深いコンテンツとの親和性高）
- 副軸: ASPアフィリエイト（書籍・ツール・サービス）
- 参考: 内向哲学（615人×¥500-1000/月）

### dec-2026-03-27-no-cross-referral
**3ブランド完全独立・クロスリファラル禁止**

- 転職(career_sister) / スピ系 / self-dev は完全独立運営
- アカウント間の相互紹介は禁止（「金稼ぎ感が出てくる」）
- オーナーが同一であることは非公開
- 先例: 内向哲学/note哲学（yuma）が1人で複数独立ブランドを運営

## 参考アカウント分析

### paranoia（YouTube 38.3万登録）
- 海外自己啓発（Alex Hormozi, Matt D'Avella等）を日本語で翻訳・再解釈
- 「ようこそ。本質領域へ。」という哲学的ブランディング
- 長尺深掘り型（30-80分）、20-30代男性中心

### 内向哲学（X 3.3万+ / yuma）
- 「騒がず、ギラつかず、淡々としている」スタイル
- 内向型に完全特化した生き方戦略
- 名言: 「自分を変えたいと強く思ったときにすべきことは、人に会いに行くではなく、とことん内に籠る」
- noteメンバーシップ615人（¥500-1000/月）

### note哲学（= 内向哲学と同一人物yuma）
- note収益化・ライティングに特化した派生ブランド
- 1人が複数独立ブランドを運営する先例
