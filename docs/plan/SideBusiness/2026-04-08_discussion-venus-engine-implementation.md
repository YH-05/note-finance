## 実装内容

### ファイル: `scripts/mitsuki_divination_engine.py`

```
CLI: uv run python scripts/mitsuki_divination_engine.py
  analyze <YYYY-MM-DD> [--mbti TYPE]  → 個人分析JSON出力
  types [-o output.json]              → 144タイプ全パターン出力
```

**主要コンポーネント**:
1. `calc_venus_sign(birth_date)` — pyswisseph でVenus惑星位置を計算
2. `calc_life_path(birth_date)` — マスターナンバー(11,22,33)保持縮約
3. `calc_personal_year(birth_date, year)` — パーソナルイヤー計算
4. `_build_type_name(lp, venus_idx)` — タイプ名生成
5. `_build_type_description(lp, venus_idx)` — 恋愛パターン解説生成
6. `build_all_144_types()` — 144パターン全生成
7. `analyze(birth_date, mbti)` — 統合分析

### 依存関係追加
- `pyswisseph` — Swiss Ephemeris Pythonバインディング（天文計算）
