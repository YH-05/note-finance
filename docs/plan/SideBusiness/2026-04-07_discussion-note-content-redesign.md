# 議論メモ: note記事の内容・収益化戦略の再設計

**日付**: 2026-04-07
**参加**: ユーザー + AI
**Neo4j Discussion ID**: disc-2026-04-07-note-content-redesign

## 背景・コンテキスト

D型プロダクト設計（同日 `disc-2026-04-07-d-product-design`）の方針確定を受け、note記事の内容と収益化戦略をD型連動に再設計。旧設計（週7本×500-800字のThreads深掘り版）の問題点を解消する。

### 旧設計の問題点
1. 短すぎる（500-800字）: noteでは薄い。SEO的にも不利
2. Threadsとの差が小さい: Threads 300-400字の延長で、noteに来る理由が弱い
3. 蓄積価値が低い: 「今週のタロット」は時事的で後から読んでも価値がない
4. 有料記事がD型と重複: note有料記事¥500-3,000とココナラD型¥1,500が共食い

## 決定事項

### dec-2026-04-07-note-content-model

#### 1. 無料記事の再設計

| 項目 | 旧 | 新 |
|------|-----|-----|
| 頻度 | 7本/週 | **6本/週** |
| 文字数 | 500-800字 | **5,000-6,000字** |
| テーマ | Threadsの深掘り | **D型4テーマ特化 + みつきコラム×2** |
| 構造 | 単一構造 | **前半無料 + 後半有料** |

#### 2. 曜日テーマ配分

| 曜日 | テーマ | D型連動先 | マガジン |
|------|--------|----------|---------|
| 月 | 恋愛×自己理解 | → 恋愛パターン分析 ¥1,500 | 恋愛×自己理解 |
| 火 | 仕事×自己理解 | → 仕事スタイル分析 ¥1,500 | 仕事×自己理解 |
| 水 | 人間関係×自己理解 | → 人間関係マップ ¥1,500 | 人間関係×自己理解 |
| 木 | ストレス×自己理解 | → ストレス反応パターン ¥1,500 | ストレス×自己理解 |
| 金 | みつきコラム | ファン化促進（**完全無料**） | みつきコラム |
| 土 | みつきコラム | 前半無料+後半有料 | みつきコラム |

#### 3. 前半無料 + 後半有料モデル

1記事 5,000-6,000字の構成:

```
【無料部分 ~3,000字】
1. 悩みフック導入（~500字）
2. 心理学×占いの解説（~1,500字）
3. セルフチェック簡易版（~1,000字）

── ここから有料 / メンバー限定 ──

【有料部分 ~3,000字】  単品¥500 or メンバーシップで読み放題
4. みつきの読み解き（~1,500字）
5. 実践ワーク + ココナラD型CTA（~1,500字）
```

#### 4. 販売形態

| 購入方法 | 価格 | 対象 |
|---------|------|------|
| 単品購入 | **¥500/本** | 非メンバー |
| メンバーシップ | **¥500/月** | メンバー（読み放題） |

メンバーシップ加入の経済的動機:

| 読み方 | 月額コスト |
|--------|----------|
| 単品購入（¥500 × 月20本） | ¥10,000 |
| **メンバーシップ** | **¥500** |

→ 「1本で元が取れる」→ 即メンバー化の動機

#### 5. 旧有料記事の廃止

旧設計（note単独有料記事）:
- ~~数秘術 自己理解鑑定書 ¥500-1,000~~ → 廃止（D型プロダクトに統合）
- ~~数秘術 自己探求ガイドブック ¥2,000-3,000~~ → 廃止（D型プロダクトに統合）
- ~~タロット×心理学 深掘り記事 ¥300-500~~ → 廃止（前半無料+後半有料モデルに移行）

#### 6. 完全無料サンプル記事（週1本）

週5本のうち1本は、D型テーマを**週替わりで完全無料**（後半も含め全文公開）とする。

| 週 | 完全無料テーマ | 他4本 |
|----|-------------|-------|
| 第1週 | **仕事×自己理解** | 恋愛(有料)+人間関係(有料)+ストレス(有料)+コラム(有料) |
| 第2週 | **人間関係×自己理解** | 恋愛(有料)+仕事(有料)+ストレス(有料)+コラム(有料) |
| 第3週 | **ストレス×自己理解** | 恋愛(有料)+仕事(有料)+人間関係(有料)+コラム(有料) |
| 第4週 | **恋愛×自己理解** | 仕事(有料)+人間関係(有料)+ストレス(有料)+コラム×2 |

加えて**金曜みつきコラムは毎週完全無料**。土曜コラムは前半無料+後半有料。

毎週の内訳:
- 完全無料: **2本**（D型テーマ1本 + 金曜コラム1本）
- 前半無料+後半有料: **4本**（D型テーマ3本 + 土曜コラム1本）

**狙い**:
1. 後半のクオリティを体験させ「他の記事の後半も読みたい」→メンバーシップ加入
2. 5,000字全文がSEO対象（有料記事は前半3,000字のみ）
3. 全文無料はSNSでシェアされやすい（拡散効果）
4. 月1回ずつ全テーマのクオリティを体験可能

#### 7. メンバーシップとの棲み分け

| | 無料部分（前半） | 有料部分（後半） | メンバー限定（既存） |
|--|----------------|----------------|------------------|
| 役割 | SEO・新規獲得 | コンバージョン・D型導線 | 居場所・リテンション |
| トーン | 「知りたい」を刺激 | 「もっと深く」の期待に応える | 「ここにいたい」 |
| CTA | なし | ココナラD型 | CTA付き10本/CTAなし2本 |

## 全体ファネル（最終版）

```
Threads（認知）週35投稿
  │ S5スロットで週4回note誘導
  ▼
note前半 無料（SEO + 新規獲得）~3,000字
  ├──→ 後半を単品購入 ¥500
  │     → 「毎回¥500は高い」→ メンバーシップ加入 ¥500/月
  ├──→ メンバーシップ「じぶん読解室」¥500/月
  │     → 後半読み放題 + 居場所コンテンツ（月タロット/水Tips/金星座 + 月次特別）
  │     → 限定記事内CTA → ココナラD型
  └──→ 記事内CTA → ココナラD型 ¥1,500
         → コレクション動機 → 総合版 ¥5,000
```

### dec-2026-04-07-content-rotation: 3軸ローテーションによる内容多様性確保

| 軸 | ローテーション | パターン数 |
|----|-------------|-----------|
| 心理学理論 | 愛着理論/ユング元型/エニアグラム/交流分析TA/発達心理学/恋愛心理学 | 6 |
| 占い軸 | 第1週タロット起点/第2週星座起点/第3週数秘起点/第4週総合テーマ | 4 |
| 切り口 | 悩み解決型/発見型/事例型/ワーク型 | 4 |

組み合わせ: 6×4×4 = **96パターン**（各テーマ月4本で2年分）

### dec-2026-04-07-tarot-images: タロットカードAI生成画像 + ディスプレイ設計

**生成ツール**: Google Gemini（Imagen 3）
**スタイル**: 水彩/パステル調、みつきブランド（温かい/詩的/内省的）に統一
**保存先**: `creator/mitsuki/images/tarot/`

**初期生成**: 大アルカナ22枚 × 2バリエーション = 44枚
- 全体図（冒頭ヒーロー用）
- 別アングル/クローズアップ（解説内インライン用）

**記事内の配置（3箇所）**:

| 配置 | 画像内容 | 生成方法 |
|------|---------|---------|
| サムネイル | カード+記事タイトル+ブランドカラー合成 | テンプレート1つで自動合成（差し替えのみ） |
| 冒頭ヒーロー | カード全体図 | Gemini生成（一度きり、再利用） |
| 解説内インライン | カード別アングル/クローズアップ | Gemini生成（一度きり、再利用） |

**使い回しの仕組み**: カード画像44枚+サムネイルテンプレート1つを初期投資で作成。以降は記事ごとにカード+タイトルを差し替えるだけ。星座12種・数秘12種も同様の仕組みで後日追加。
