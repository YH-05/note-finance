# 議論メモ: キャリアお姉さん コンテンツ価値分析と有益投稿の定義変更

**日付**: 2026-03-25
**参加**: ユーザー + AI

## 背景・コンテキスト

キャリアお姉さん（career_sister）のThreads/Instagram投稿コンテンツについて、ユーザーから「役立つものが少ない。他のユーザーは真に有用な情報に対して金を払う」という問題提起があった。

全21投稿の下書き（week_2026-03-24）とペルソナ定義・投稿アルゴリズムを精査し、根本的な問題を特定した。

## 議論のサマリー

### 問題の特定

1. **6つのコア主張のうち5つが精神論**
   - 「動いたほうがいい」「失敗しても学びになる」「年収は後からついてくる」等
   - 共感は得られるが、金を払う動機にならない

2. **具体的な非公開データ・独自情報がゼロ**
   - 企業名・業界名を一切出さない方針が具体性を殺している
   - 「A4で2枚」「PDFで送れ」等のTipsはどの転職サイトにも書いてある

3. **有料コンテンツで人が金を払う3要素が全て欠如**
   - 非公開データ（情報の非対称性）
   - 再現可能なフレームワーク（具体的手順書）
   - アクセス（人やネットワーク）

4. **AI生成の失敗談に実在感が欠ける**
   - 面接落ちた企業名、不採用理由、具体的数字が曖昧

### 改善の方向性

Phase 1（すぐ実施）: 有益投稿の定義を「データに基づく市場インサイト」に変更
Phase 2（中期）: note.com有料マガジンとして「転職ルート別ガイド」を販売
Phase 3（長期）: コミュニティ化（Threads→note有料→Discord/オープンチャット）

## 決定事項

1. **有益投稿の定義変更**: 「一般的アドバイス（精神論）」→「データに基づく市場インサイト」
2. **テーマプール拡張**: T9（転職市場データ）とT10（業界別ルートマップ）を追加
3. **データ投稿枠**: 週21投稿中最低3本を「独自データ投稿」に割り当て
4. **コア主張追加**: 「データで語る」を7番目のコア主張として追加
