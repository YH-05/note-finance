## 議論のサマリー

### 1. 占術エンジンの最終構成

数秘術 + 惑星星座の組み合わせについて具体的な占い方法・鑑定書構成を検討。

- 数秘術は **LP + Personal Year のみ**（案A採用）。Expression Number / Soul Urge はフルネーム入力が必要で不採用。
- みつきを **恋愛 + 自己愛専門** に絞る方針に伴い、惑星はテーマ対応で見直し:
  - Venus → 恋愛 + 自己愛（Venusは愛情スタイルと自己価値の両方を司る）→ **採用**
  - Mars（仕事）/ Mercury（人間関係）/ Saturn（ストレス）→ テーマ削除に伴い **不採用**
- **エニアグラム不採用**: MBTIで心理学の権威づけは十分。設計が複雑になるだけ。
- **Sun sign（一般12星座）完全除外**: エンジンから除外、Threads投稿からも除外。

最終エンジン構成:
```
入力: 生年月日8桁のみ（+ MBTI任意）
数秘術: LP + Personal Year
惑星星座: Venus のみ
パターン数: 144（LP12 × Venus12）
```

### 2. タロット・星座のチャネル分離

- **星座**: Threads投稿からも完全除外。
- **タロット**: note・ここナラでの販売がメイン。Threadsではサブ要素（20%）として恋愛文脈で絡める。
- チャネル別役割: Threads=共感・集客、note=有料記事・メンバーシップ、ここナラ=D型PDF・タロット鑑定

### 3. 占いオタク感の出し方

YouTube現役占い師の「成功する占い師は占いオタクで、そのことばかり喋っている」という体験談を踏まえ、
「占術を完全に裏側に隠す」方針を修正。

→ **「入口は恋愛悩み、読み解きの過程で占い知識が自然に光る」** 構造に。
→ シェフの比喩: 食材オタクだがメニューは客が食べたい料理。

### 4. Threads投稿カテゴリ再設計

| カテゴリ | 配分 | 内容 |
|---------|------|------|
| 恋愛悩み→占い読み解き | 35% | 入口は悩み、途中で占い知識が光る |
| 愛着スタイル解説 | 25% | 不安型/回避型のリアルな行動パターン |
| タロット×恋愛 | 20% | タロットと恋愛の感覚を結びつける |
| みつきパーソナル | 10% | 占いへの情熱、自分の失敗談 |
| 自己肯定感 | 10% | 自分を後回しにしがちな人への寄り添い |

### 5. ペルソナ全面改訂

- キャラクター: **ギャル × 世話好きおばちゃん**
  - ギャル面: 恋バナ大好き、占いオタク、「まじで」「めっちゃ」、絵文字多用
  - おばちゃん面: 悩む人を放っておけない、「大丈夫だからね」「あんたは悪くない」
- 体験談ストーリーテリング: 五感描写・時間場所・心の声でリアリティを出す
- 体験談パターン: みつき自身 / 友達・知人の事例 / DM・コメントからの架空事例
