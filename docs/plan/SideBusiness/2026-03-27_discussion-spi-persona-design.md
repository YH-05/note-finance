## 決定事項

### dec-2026-03-27-spi-persona-mitsuki
**スピ系アカウントのペルソナを「みつき（美月）」に確定**

- キャラクター型ペルソナ（人格あり）、career_sisterと並ぶ形で設計
- 美月の「月」→ 占星術・タロット(Moonカード)・自然サイクルとの親和性
- 温かみがあり親しみやすい

**ハンドル案**: `@mitsuki_jibunguide`（確定は開設時に最終確認）

### dec-2026-03-27-spi-bio-style
**Bioスタイルを問題提起型（親密感）に確定**

切り口: 「自分のことがよくわからない、そんな人のために」

```
みつきです。

「自分のことがよくわからない」
そんな人のために。

タロット×星座×数秘術を
心理学の言葉で読み解く。

占いを「自分を知るツール」に変える人。
```

### dec-2026-03-27-spi-backstory
**バックストーリーを共感型（自分も苦労した経験）に設定**

```
「ずっと自分のことがわからなかった。
何度占いを試しても
「当たるかな？」で終わっていた。

心理学を学んで、占いをかけ合わせたとき
初めて「あ、これが私のパターンなんだ」
と思えた。」
```

→ Type B内的探究型は自己探求の経験者が多く最も共感できる。
→ 占い師としての権威ではなく「同じ道を先に歩いた人」としての信頼感を醸成。

### dec-2026-03-27-spi-writing-style
**投稿文体を「詩的フック → 心理学分析」ミックス型に確定**

```
詩的フック（2-3行）
  ↓
心理学的解説・分析（50-100字）
  ↓
問いかけ・CTA（1-2行）
```

**サンプル投稿（タロット型）**:
```
占いって
「当たる/外れる」じゃない。

タロットの「塔」のカードが持つ意味は
心理学的に言えば「認知的再評価」の瞬間。
おぜりがこみ上がったときこそ
手放しと再構成のチャンスがある。

今週、何かが崩れている人へ──
それは「終わり」じゃなくて「始まり」かもしれない。
```

**サンプル投稿（星座型）**:
```
天秤座が
「どちらでもいい」と言いながら
葛藤している理由。

それ、愛着理論で言う「均衡欲求」から来ている。
他者の感情と自分の欲求を同時に保とうとする──
天秤座の「公平性」はそこから生まれている。

天秤座の人、これ刺さった？
```
