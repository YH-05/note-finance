# 議論メモ: みつき Threads/noteアカウント開設・プロフィール確定

**日付**: 2026-03-27
**参加**: ユーザー + AI

## 背景・コンテキスト

みつき（美月）アカウントの運用基盤（ペルソナ・投稿アルゴリズム・スキル・コマンド）が整備済み。
今回はInstagram/Threadsアカウントを実際に開設し、プロフィール設定を確定した。

## 議論のサマリー

- Instagram/Threadsアカウントを開設（Instagram連携）
- プロフィール画像を作成・設定
- 表示名を複数案から「みつき|占いで自分を知る」に絞り込み
- Threads Bioを「問いかけトーン」→「自己紹介スタイル」に方針変更して確定
- note Bioを「語りかけ型・役立ちが伝わる」スタイルで確定
- `creator/mitsuki/persona.md` を更新済み

## 決定事項

1. **表示名**: `みつき|占いで自分を知る`（Threads・note共通）
2. **Threads Bio**: 絵文字付き自己紹介スタイル
   ```
   占い🔮×心理学❤️で「自分を知る」を発信しています。
   タロット・星座・数秘術を心理学の視点で読み解いて
   自分のパターンや強みに気づくヒントをお届けします。
   占いを「当たる/外れる」ではなく
   「自己理解のツール」として使いたい人へ💫
   ```
3. **note Bio**: 語りかけ型（読者の悩みから入る構成）
   ```
   「なんで自分はこうなんだろう」
   そう思ったことがある人へ。

   タロット・星座・数秘術を心理学の視点で読み解いて
   あなた自身のパターンや強みに気づくお手伝いをしています。

   「当たるかどうか」より「自分を理解できるかどうか」。
   一緒に、自分の地図を描いていきませんか。
   ```
