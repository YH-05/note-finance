## 2. Threads急成長戦略（3ヶ月→15,000F）

### Phase A: 初期ブースト（Week 1-2）

- **70投稿の先行作成**（14日×5スロット）
- **感情フック型を集中投下**:
  - 「青春を無駄にした」感覚（Story: 18歳の後悔→ストア派で救われた）
  - 「常に他人より遅れてる」不安（Story: 社会的比較の科学 + 対処法）
  - 「夜にやる気爆発→朝消える」サイクル（Story: コルチゾール日内変動の科学）
  - 「モチベーション待ち」の罠（Story: まず動き、感情は後からついてくる）
- **ハッシュタグ**: #自己啓発 #内向型 #ストア派 ローテーション
- **3-2-5ルール**: 投稿3+他アカへリプ2+いいね5（毎日）

### Phase B: バズ狙い（Week 3-6）

- **長文スレッド投稿**（Thread形式3-5連投）:
  - 「90日ストイシズム実践で起きた7つの変化」
  - 「2分ルールが人生を変えた科学的理由」
  - 「Deep Workを1ヶ月試した結果」
- **Transformation投稿**（ビフォーアフター型）:
  - 完璧主義→ミニマル規律
  - モチベーション依存→システム化
  - 意志力消耗→環境デザイン
- **3-2-5ルール維持** + **投票・質問形式**でエンゲージメント

### Phase C: スケール（Week 7-12）

- **note→Threads変換パイプライン**: note記事の見出し→各1投稿に分割
- **シリーズ化**: 「ストア派の教え #01-30」「2分で始める習慣 #01-20」
- **フォロワー参加型**: 「あなたの朝ルーティンは？」「今週読んだ本は？」

→ 月6-8本の有料コンテンツ → メンバー維持率向上

### 無料→有料の導線

```
Threads投稿（5本/日）
  → プロフィールリンク → note
    → 無料記事（価値証明）
      → 記事末尾「メンバーシップでは…」
        → ¥1,000/月登録
```

**重要ルール（career Tip準拠）**:
- アフィリリンクは本文ではなくコメント欄に（ER低下防止）
- Threads → note リンクはプロフィール設置が安全
- 投票・アンケートで次の投稿ネタを収集

## 4. 書籍アフィリ戦略

### Amazon Associates 運用設計

| 項目 | 内容 |
|------|------|
| 配置 | note書評記事内にAmazonリンク、Threadsはコメント欄 |
| 頻度 | 月4-5冊の書評note + Threads書籍紹介週2-3回 |
| 報酬率 | 書籍3-4%（1冊1500円→報酬45-60円） |
| 月間目標 | 100-300クリック→10-30購入→¥500-2,000 |
| 戦略的価値 | 金銭<ブランド信頼性。「この人は本を読んでいる」証明 |

### 推奨書籍リスト（ターゲット: 内向型男性）

**Tier 1: コア推奨（定番として何度も紹介）**
- 自省録（マルクス・アウレリウス）
- Atomic Habits（James Clear）
- Deep Work（Cal Newport）
- Thinking in Bets（Annie Duke）

**Tier 2: 深掘り（月1冊ペースで書評）**
- Quiet（Susan Cain）— 内向型の科学
- Tiny Habits（BJ Fogg）— 行動デザイン
- Decoding Greatness（Ron Friedman）— リバースエンジニアリング
- Building a Second Brain（Tiago Forte）— 知的生産

**Tier 3: ニッチ（差別化・権威性向上）**
- Letters from a Stoic（セネカ）
- The Now Habit（Neil Fiore）
- Willpower Instinct（Kelly McGonigal）

## 6. リスクと緩和策

| リスク | 緩和策 |
|--------|--------|
| 3ヶ月で15,000F未達 | 6ヶ月を現実的到達点として設定済み。有料コンテンツ品質に注力 |
| バズが起きない | EmotionalHook投稿の比率を上げる。Reddit体験談の日本語再構成で共感を狙う |
| メンバー解約率が高い | 週1本以上の有料記事で継続価値を提供。シリーズ化で「次回が読みたい」を作る |
| 書籍アフィリ低収益 | 金銭目的ではなくブランド信頼性構築として位置づけ。本業はメンバーシップ |
| みつき（スピ系）とのカニバリ | 分割軸「感じる vs 考える」を厳守。3ブランド境界線ガイドラインを策定 |
