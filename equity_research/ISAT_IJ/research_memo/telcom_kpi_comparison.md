## 1. KPI フレームワーク — インドネシア通信セクターで追うべき指標

### 1-1. カテゴリ別 KPI 全体像

| カテゴリ | KPI | 定義・単位 | なぜ重要か |
|---------|-----|-----------|-----------|
| **損益 (PL)** | Revenue | IDR bn, YoY% | 規模・成長モメンタム |
| | EBITDA / Margin | IDR bn, % | キャッシュ創出力の代理指標 |
| | EBITDA - CapEx Margin | % | 実質的なキャッシュ利回り |
| | Net Income / EPS | IDR bn, IDR/株 | 株主帰属利益 |
| | D&A | IDR bn | 非現金費用（設備更新サイクルを反映） |
| **キャッシュフロー** | CapEx | IDR bn | 設備投資絶対額 |
| | CapEx / Revenue (強度) | % | 資本集約度（業界平均 **~22%**） |
| | OCF | IDR bn | 営業キャッシュフロー |
| | FCF = OCF − CapEx | IDR bn | 配当・債務返済余力 |
| **バランスシート** | Net Debt / EBITDA | 倍 | 財務健全性（<2x が標準） |
| | D/E ratio | 倍 | 財務レバレッジ |
| **加入者・ARPU** | 総加入者数 | mn | 市場規模・シェア |
| | 後払い比率 (Postpaid %) | % | 高ARPU・低解約セグメント比率 |
| | 解約率 (Churn) | %/月 | 顧客維持力（インドネシアは高め） |
| | ARPU ブレンド | IDR/月 | 収益密度（業界平均 IDR 35k〜45k） |
| | ARPU 後払い / 前払い | IDR/月 | セグメント別収益品質 |
| **データ指標** | データペイロード | PB/期 | トラフィック成長トレンド |
| | データ収益化率 (Data Yield) | IDR/GB | ネットワーク収益効率 |
| | デジタル収益比率 | % | 音声→データ転換の進捗 |
| **インフラ** | 総BTS / 4G BTS / 5G BTS | 局 | ネットワーク品質・次世代展開 |
| | 4G人口カバレッジ | % | サービス可能市場 |
| | 光ファイバー延長 | km | FMC対応・バックホール強化 |
| **市場シェア** | 収益シェア / 加入者シェア | % | 競争地位と規模の経済 |
| **収益性** | ROE / ROIC / ROA | % | 資本効率（スペクトラム・設備含む） |
| **バリュエーション** | EV/EBITDA | 倍 | セクター標準（Indonesia 4〜6x） |
| | PER | 倍 | 利益ベース評価 |
| | Dividend Yield | % | インカム投資家の基準 |
| | Dividend Payout Ratio | % | 配当方針の確認 |
| **デジタル/AI** | AI・クラウド収益 | IDR bn / % | TechCo転換の進捗指標 |
| | NPS | ポイント | ブランド・顧客満足度 |

### 1-2. インドネシア固有の注目ポイント

| 項目 | 背景と重要性 |
|------|------------|
| **スペクトラムコスト/収益** | 業界平均12.2%（APAC中央値8.7%）。TLKM ~5% vs IOH/EXCL ~12-13%の構造差が収益性に直結。[GSMA 2023](https://www.gsma.com/connectivity-for-good/spectrum/wp-content/uploads/2023/11/GSMA_Sustainable-spectrum-pricing-to-boost-Indonesias-digital-economy.pdf) |
| **スターターパック価格** | 2024年: 3GBで IDR 10,000の超低価格が高解約・ARPU希薄化を招いた。2025年10月: Komdigiが最低価格をIDR 35,000に引き上げ→ARPU修復の転換点 |
| **CapEx/EBITDA** | FCF創出の直接規定因子。TLKM: CapEx強度14〜16%でFCF潤沢。IOH・XLSmart: 21〜26%と高く FCF余地が限定的 |
| **合併シナジー進捗** | IOH（2022合併）・XLSmart（2025合併）ともにMOCN統合・調達効率化の実現速度が評価軸 |
| **700MHz/2.6GHzオークション** | 2026年Q2予定。IOHのFibreCo売却益（~$700mn）が自然ヘッジ。XLSmartは900MHz返還（2026年12月）でBHP削減 |

## 6. 各社モニタリング優先 KPI

### ISAT（IOH）
1. **ARPU** — +6.4%（FY2025）を2026年も維持できるか。スターターパック正常化の2026年継続効果
2. **FCF** — IDR 3,083bn (FY2025) → FY2026E での拡大軌道（FibreCo収益+CapEx安定）
3. **5G展開** — 6,800局 → 2026年の700MHz/2.6GHz落札後の拡大速度
4. **後払い加入者** — +19.7% YoY モメンタムの継続。後払いARPU/前払いARPUの開示改善
5. **ND/EBITDA** — 0.39x は業界最低。5G CapEx投下後の推移（0.6x以内が許容）

### TLKM
1. **FY2025 full year（2026年4月公開予定）** — 9M25の-2.3% YoYがQ4で改善しているか
2. **Telkomsel ARPU** — IDR 43,400（Q3-2025）から IDR 45,000+への継続的回復
3. **TLKM30リストラコスト削減** — 55→22社の削減で IDR 6T/年の目標がどこまで実現するか
4. **CapEx効率** — 9M2025でCapEx -11.7% YoYを維持し、高FCFを維持できるか
5. **配当政策** — Payout 89%・Yield 7.4%は維持可能か（Danantara関連政策変更リスク）

### XLSmart
1. **シナジー実現加速** — $22-50M（初年度）から $300-400M（最終目標）への軌道に乗れるか
2. **ARPU vs. 加入者のトレードオフ** — Q4のARPU IDR 44,800 vs. 加入者73mn低下を継続するか、2026年に均衡点に達するか
3. **ネットワーク統合完了（2026年6月）** — 85%→100%完了でのOpEx削減額
4. **900MHz返還（2026年12月）** — 返還後のBHP削減額と再ファーミング（5G転用）戦略
5. **CapEx 2026** — ガイダンス IDR 15-20T が実際にどの水準で着地するか（FCFへの直撃）
