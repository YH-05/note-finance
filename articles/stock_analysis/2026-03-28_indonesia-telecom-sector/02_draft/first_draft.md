# インドネシア通信セクター完全ガイド：3社寡占体制で投資機会はどこに？

人口2.7億人超、ASEAN最大の経済大国インドネシア。その通信セクターは2025年、XL Axiata とSmartfren の大型合併を経て「3社寡占」体制へと移行しました。市場規模は[USD 137億](https://www.mordorintelligence.com/industry-reports/indonesia-telecom-market)と巨大ですが、成長率は鈍化傾向にあります。

本記事では、インドネシア通信セクターの主要銘柄（TLKM、ISAT、EXCL、TOWR、TBIG）を横断的に分析し、投資機会とリスクを整理します。

---

## 1. 市場構造：実質3オペレーターへの集約

2025年4月16日、XL Axiata と Smartfren が正式に合併し、[PT XLSMART Telecom Sejahtera Tbk](https://www.xlaxiata.co.id/en/news/xl-axiata-successfully-concluded-q1-2025)（IDX: EXCL）が誕生しました。これにより、インドネシアのモバイル市場は事実上3グループに集約されています。

**モバイル市場シェア（2025年）**

- **Telkomsel（TelkomGroup）**：加入者[1.59億人、シェア約51%](https://www.mordorintelligence.com/industry-reports/indonesia-telecom-market)。4G基地局23.5万基、5G基地局4,009基を展開する圧倒的リーダー
- **Indosat Ooredoo Hutchison（IOH）**：加入者[9,470万人、シェア約28%](https://www.thejakartapost.com/adv/2025/02/11/indosat-record-38-net-profit-deliver-standouts-performance-throughout-2024.html)。ARPU成長+6.6%と「量より質」戦略
- **XLSmart**：合併により加入者[9,450万人、シェア約25%](https://www.xlaxiata.co.id/en/news/xl-axiata-successfully-concluded-q1-2025)。統合シナジーとスペクトラム効率化が鍵

3社で市場収益の約95%を占める「健全な寡占」が形成され、かつての激しい価格競争から脱却しつつあります。

## 2. 各社の財務パフォーマンス

### Telkom Indonesia（TLKM）：安定配当の巨艦

Telkom Indonesia は[FY2024に連結売上IDR 150.0兆](https://www.telkom.co.id/sites/news-resources/en_US/news/telkom-2024-financial-report,-telkom-wraps-up-2024-on-a-high-note,-achieving-idr-150-trillion-in-consolidated-revenue-2959)を達成しましたが、成長率は+0.5%と鈍化しています。一方、EBITDA マージン50.0%、純利益マージン15.8%と収益性は高水準を維持。

注目すべきは[配当性向89%（DPS 212.47 IDR）](https://www.telkom.co.id/sites/news-resources/en_US/news/telkom-2024-financial-report,-telkom-wraps-up-2024-on-a-high-note,-achieving-idr-150-trillion-in-consolidated-revenue-2959)と最大3兆IDRの自社株買いプログラムです。政府系企業（Danantara経由で52.1%保有）として高い株主還元を継続しています。

[Q1 2025は売上IDR 36.6兆、EBITDA マージン49.8%](https://www.telkom.co.id/sites/news-resources/en_US/news/telkom-q1-2025-financial-report,-strengthening-digital-business,-telkom-records-consolidated-revenue-of-idr-36.6-trillion-in-early-2025-2983)と安定推移。トップラインの伸びは限定的ですが、InfraNexia スピンオフ（後述）による価値アンロックが次の成長ドライバーです。

### Indosat Ooredoo Hutchison（ISAT）：成長率No.1

IOHは[FY2024に売上+9.1%、純利益+38.1%](https://www.telecomreviewasia.com/news/industry-news/12445-indosat-reports-strong-growth-in-2024/)と、セクター内で最も高い成長率を記録しました。加入者数は4.1%減の9,470万人でしたが、ARPU は+6.6%のIDR 38,000に上昇しており、低価値ユーザーの整理と高付加価値化が進んでいます。

[FY2025は売上IDR 56,518B（+1.1%）、純利益IDR 5,818B（+10.3%）](https://quartr.com/companies/pt-indosat-ooredoo-hutchison-tbk_19816)と、成長率はやや鈍化したものの着実に増益を維持。[DBS Vickers は IOH を「テレコムユニバースで最良のgrowth outlook」](https://www.dbs.com.sg/treasures/aics/templatedata/article/recentdevelopment/data/en/DBSV/022025/ISAT_IJ_01312025.xml)と評価しています。

2026年のガイダンスはmid-to-high single digit成長で、CapExはIDR 13兆を計画しています。

### XLSmart（EXCL）：合併シナジーに賭ける

[XLSmart はFY2025に売上IDR 42.5兆（+23%）](https://jakartaglobe.id/tech/xlsmart-posts-25-billion-revenue-in-2025-after-xl-axiatasmartfren-merger)を達成。EBITDA は IDR 20.1兆（+13%）、純利益 IDR 3兆と、合併効果が早くも数字に表れています。

[2026年末までに$250-300Mの合併シナジー](https://www.investing.com/news/company-news/xl-axiata-q1-2025-slides-revenue-growth-amid-profit-decline-merger-integration-underway-93CH-4023425)を目標としており、ネットワーク統合・重複コスト削減が進行中。5Gを33都市に拡大し、ARPU は+15% YoYと改善が続いています。

バリュエーション面では[EV/EBITDA 3.8x（FY25）](https://www.minichart.com.sg/2025/01/06/asean-telecom-outlook-2025-navigating-challenges-and-opportunities-in-a-maturing-market/)と、ASEAN同業（タイのTrue Corp: 9x）と比較して大幅に割安。合併シナジーの実現度合いが株価の鍵を握ります。

## 3. タワー企業：テレコムの「不動産」

インドネシアのタワー市場は[USD 18億（2025年）、CAGR 4.18%で2030年にUSD 22.1億](https://www.mordorintelligence.com/industry-reports/indonesia-telecom-market)に成長すると予測されています。

**Tower Bersama Infrastructure（TBIG）** は[H1 2025に売上IDR 3.45兆、EBITDA IDR 2.97兆](https://www.tower-bersama.com/en/news/pt-tower-bersama-infrastructuretbk-tbig-announces-its-first-half-2025-financial-performance)を計上。[2025年9月時点でテナント42,771、サイト24,318](https://www.tower-bersama.com/en/news/pt-tower-bersama-infrastructuretbk-tbig-announces-its-third-quarter-2025-financial-performance)と安定した基盤を持ちます。

**Sarana Menara Nusantara（TOWR）** はDjarum グループ傘下で、インドネシア最大のタワーポートフォリオを保有しています。

タワー企業はモバイルオペレーターへの「インフラ貸し」ビジネスのため、収益の安定性が高い一方、オペレーター統合によるテナント集約リスクがあります。XLSmart 合併後のサイト最適化は注視すべきポイントです。

## 4. 成長ドライバーとカタリスト

### InfraNexia スピンオフ

Telkom Indonesia 最大のカタリストが[InfraNexia の分離](https://www.telkom.co.id/minio/show/data/lampiran/1762742055847_original_9M25-Infranexia-Roadshow-Presentation.pdf)です。2025年12月に Phase 1 が完了し、光ファイバー資産IDR 35.8兆が移管されました。Phase 2 は2026年下半期に完了予定で、総資産価値は IDR 90兆に達します。

現在の光ファイバー利用率は約40%にとどまっており、InfraNexia による資産アンロックと利用率改善が Telkom の隠れた価値を顕在化させる可能性があります。

### Danantara 改革

[政府系投資庁Danantara](https://katadata.co.id/finansial/bursa/698c28ee9d8e3/bocoran-danantara-mau-rampingkan-telkom-tlkm-pangkas-puluhan-entitas-usaha)は Telkom の子会社を約55社から約22社に削減する計画で、年間CapEx/OpEx 6兆IDR の削減を目標としています。コングロマリット・ディスカウントの解消が期待されます。

### 5G 展開

[5Gカバレッジは2025年末で住宅エリアの6.33%、2026年目標は8.5%](https://telecomlead.com/4g-lte/indonesia-sees-major-mobile-network-gains-as-4g-surpasses-90-coverage-5g-expansion-remains-urban-focused-122145)です。Telkomsel が56都市に2,100基超の5Gサイトを展開しリードしていますが、本格展開には[3.5GHz帯が不可欠で、そのオークションは2028年予定](https://www.gsma.com/connectivity-for-good/spectrum/wp-content/uploads/2025/03/GSMA_Accelerating-5G-in-Indonesia.pdf)です。

## 5. リスク要因

1. **市場成熟化**：MNO市場のCAGR は[わずか1.01%（2025-2033）](https://www.mordorintelligence.com/industry-reports/indonesia-telecom-market)。トップライン成長の限界
2. **5Gのスペクトラム制約**：3.5GHz帯が2028年まで不在。mid-band が1.8/2.1/2.3GHz のみで本格5Gは遅延
3. **OTT プラットフォームの脅威**：[ハイパースケーラーやOTTがテレコムのバリューチェーンを侵食](https://www.ey.com/en_id/insights/telecommunications/top-10-risks-for-telecommunications-in-2025)するリスク
4. **規制・政治リスク**：Danantara改革は政権交代の影響を受ける可能性。規制環境は予測困難
5. **XLSmart 統合リスク**：合併シナジー実現は2026年末が目標だが、ネットワーク統合・組織統合の遅延リスク

## 6. 投資視点：セクター内のポジショニング

**インカム重視** → **Telkom Indonesia（TLKM）**
配当性向89%、自社株買い実施。安定したキャッシュフローで高配当。ただしトップライン成長は限定的。InfraNexia スピンオフが中長期のカタリスト。

**グロース重視** → **Indosat（ISAT）**
セクター最高の利益成長率。ARPU改善と「量より質」戦略。DBS Vickers が「最良のgrowth outlook」と評価。

**バリュー / ターンアラウンド** → **XLSmart（EXCL）**
EV/EBITDA 3.8x と ASEAN 同業比で割安。合併シナジー実現が鍵。高リスク・高リターン。

**安定インフラ** → **TOWR / TBIG**
タワーの「不動産」ビジネス。安定収益だが成長はモバイルオペレーターに連動。テナント集約リスクに注意。

---

## まとめ

インドネシア通信セクターは、業界統合による「健全な寡占」形成期にあります。市場全体の成長率は鈍化していますが、各社の戦略は明確に分化しており、投資スタイルに応じた選択肢が存在します。

短期的には XLSmart の合併シナジー実現度合い、中長期的には InfraNexia スピンオフの価値実現と3.5GHz帯オークション（2028年）が、セクター全体の方向性を左右するでしょう。

ASEAN の中でもバリュエーションが割安な水準にあるインドネシア通信セクターは、新興国テレコムへのエクスポージャーを求める投資家にとって、注目に値するセクターです。
