### 4. COTレポートの構造（TFF形式）

CFTC発行の「Traders in Financial Futures (TFF)」報告書:

| カテゴリ | 内容 |
|---------|------|
| **Dealer/Intermediary** | 銀行・証券会社のディーラー。マーケットメイカー |
| **Asset Manager/Institutional** | 年金基金、保険会社、投資信託、ETF運用会社。**機関投資家** |
| **Leveraged Funds** | ヘッジファンド。投機的ポジション |
| **Other Reportables** | その他の大口トレーダー |

- 毎週火曜日のデータを金曜日に公開
- 20名以上のトレーダーがポジションを保有する市場のみ対象
- **重要**: 「マネージドマネー」（Leveraged Funds相当）のネットポジションが最も注目される

**出典**: CFTC公式サイト, Britannica Money, StoneX Financial

### 6. イールドカーブ逆転の歴史的分析

- 1976年以降: 7回の2Y-10Y逆転 → 6回の景気後退（1例外: 2022-2024）
- 中央値リードタイム: 逆転から後退まで14ヶ月（18〜92週）
- **重要パターン**: 後退は逆転中ではなく、**再スティープニング後に始まる**
- 2022-2024の逆転後、2024年から再スティープニング開始 → **2025-2026が要注意期間**

**出典**: eco3min.fr, Chicago Fed, NY Fed

## Phase 3: 論点抽出

### ブル（強気）要因 ─ 10年国債に対してポジティブな見方

1. **フライトトゥクオリティ**: 地政学・株価下落時に機関投資家が10年債に資金シフト
   - 根拠: 2026年3月の中東危機で10Y利回りが3.95%まで低下
   - ソース: FinancialContent Market Minute (2026-03-02)

2. **COT大口スペキュレーターのネットロング**: 2026年3月に+119,513枚と大幅な強気ポジション
   - 根拠: InvestMacro (2026-03)
   - 解釈: 大手投機筋が国債価格上昇（利回り低下）を予想

3. **イールドカーブ再スティープニング後の歴史的パターン**:
   - 根拠: 過去6/7回の逆転後、後退局面で10年債需要が増加
   - 現在: 2024年に再スティープニング完了 → 後退前夜の可能性

4. **FRBの利下げ継続期待**: 2025年に3回利下げ実施、2026年に1-2回追加見込み
   - 根拠: Charles Schwab 2026 Fixed Income Outlook
   - 効果: 短期金利低下 → 2Y利回り低下 → 10Y債の相対価値向上

5. **景気後退確率の上昇**: Moody's 49%、GS 25-30%
   - 後退時: 10年債は歴史的に価格上昇（利回り低下）

### ベア（弱気）要因 ─ 10年国債に対してネガティブな見方

1. **関税インフレ効果**: 関税 → インフレ → FRB利下げ困難 → 長期金利上昇圧力
   - 根拠: Liberation Day後の10Y急騰（4.01% → 4.58%）
   - 2025年食品価格: +2.8%（関税起因）

2. **財政赤字・国債供給増**: 財政持続可能性への懸念 → タームプレミアム上昇
   - 根拠: 「債券自警団」リスク（日経）
   - 影響: 国債大量発行 → 価格下落（利回り上昇）

3. **「米国売り」リスク**: 外国機関投資家による米国債売却
   - 根拠: 2025年4月に顕在化した「株・債券・ドル同時安」
   - 2025年Liberation Day翌週: 中国等が売却懸念 → 10Y 4.58%

4. **米国債の安全資産機能低下**:
   - 根拠: T. Rowe Price「米国債は直近の株安での避難先としての機能が低下」
   - Feb-Apr 2026: 米国加重指数 +0.54% vs 海外 +7.08%

5. **COT利益確定リスク**: 3月の+119,513枚のロングポジションは反転売り圧力になる可能性

### ニュートラル / 不確実性要因

1. **景気後退「遅延」シナリオ**: 2022-2024逆転後も後退せず → COT・イールドカーブの信頼性に疑問符
2. **地政学的不透明性**: 中東情勢 → フライトトゥクオリティvsインフレの綱引き
3. **FRBの板挟み**: 関税インフレ（利上げ方向）+ 景気減速（利下げ方向）の二律背反
4. **COTデータの限界**: 財務先物でのCOT効果は商品市場より弱い（学術研究）
