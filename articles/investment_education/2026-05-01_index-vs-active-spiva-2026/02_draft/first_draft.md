# インデックス vs アクティブをゼロから理解する｜SPIVA2026最新データで再決着

# はじめに

「プロに任せたほうが儲かるのか、それともインデックスファンドで十分なのか」という疑問は、投資を始めた多くの人が一度は抱く疑問です。

2026年3月、この論争に決定的なデータが加わりました。世界最大の指数算出機関であるS&Pダウ・ジョーンズ・インデックスが「SPIVA日本スコアカード2025年末版」を発表し、2025年末時点のアクティブファンドの成績が明らかになりました。

この記事では、SPIVAレポートの最新データをもとに、インデックスファンドとアクティブファンドの違い、プロが長期で勝てない理由、そしてコストが30年でどれほど差を生むかを、できるだけわかりやすく解説します。

# SPIVAとは

SPIVAとは「S&P Indices Versus Active」の略称で、S&Pダウ・ジョーンズ・インデックスが2002年から発行している、アクティブファンドの通知表のようなレポートです。

アクティブファンドとは、ファンドマネージャーと呼ばれる専門家が銘柄を選び、市場平均（ベンチマーク）を上回るリターンを目指して運用する投資信託のことです。一方、インデックスファンドは日経225やS&P500といった株価指数の値動きをそのままなぞる形で運用します。

SPIVAの役割は、アクティブファンドが本当にその指数（ベンチマーク）を上回ったかどうかを、客観的な数字で検証することです。現在は日本、アメリカ、欧州、オーストラリアなど9カ国以上でスコアカードが発行されており、世界中の投資家が参照する信頼性の高いデータとして知られています。

SPIVAの最大の特徴は「サバイバーシップバイアス（生存者バイアス）」を補正している点です。これは後のセクションで詳しく説明しますが、成績不振で清算・合併されたファンドも計算に含めることで、見かけ上の成績が良く見えることを防いでいます。

例えば、100本のアクティブファンドが1年後に90本になっていたとします。消えた10本は成績不振のファンドである場合がほとんどです。残った90本だけで成績を計算すると、全体の実力より高い数字が出てしまいます。SPIVAはこの落とし穴を避けるために、消えたファンドも含めて集計しています。

https://prtimes.jp/main/html/rd/p/000000004.000158903.html

# SPIVA日本2025最新データ（2026年3月発表）

S&Pダウ・ジョーンズ・インデックスが2026年3月10日に発表した「SPIVA日本スコアカード2025年末版」は、日本のアクティブファンドの成績を詳細に検証したものです。

まず2025年の単年成績から見ていきましょう。

日本大型株ファンドは、ベンチマークである「S&P/TOPIX 150」を下回ったファンドが約49%でした。これは2017年以来最も低い数字であり、珍しくプロが健闘した年といえます。ただし、これは半数近くがまだ市場平均に負けているということでもあります。

一方、日本の中小型株ファンドでは約80%がベンチマークを下回り、これは2014年以来最悪の数字でした。グローバル株式ファンドでは約87%がアンダーパフォームし、均等加重平均でのリターンが15.0%にとどまる中、ベンチマークは21.7%のリターンを記録しました。

米国株式ファンド（日本籍）はさらに厳しく、約89%がアンダーパフォームしています。ファンドの資産加重平均リターンは9.1%でしたが、ベンチマーク（米国株指数）のリターンは17.6%と大きな開きがありました。新興国株式ファンドでも約88%がアンダーパフォームし、ファンド平均23.8%に対してベンチマークは31.9%を記録しています。

また、2025年の1年間だけで全体の約8%のアクティブファンドが清算・合併によって消えています。

https://prtimes.jp/main/html/rd/p/000000004.000158903.html

さらに長期で見ると、結果は一段と厳しくなります。日本大型株ファンドでは、10年間で約83%のファンドがベンチマークを下回り、15年間でも約80%がアンダーパフォームしています。そして驚くべきことに、グローバル株式・国際株式・新興国株式の3カテゴリでは、10年・15年ともにアンダーパフォームの割合が100%に達しました。

このデータについて、S&Pダウ・ジョーンズ・インデックスのSue Leeは「6カテゴリのうち5カテゴリで、80%以上のアクティブファンドがベンチマークをアンダーパフォームした」とコメントしています。

# SPIVA米国2025データとの比較

日本だけでなく、世界最大の市場であるアメリカでも同じ傾向が確認されています。

SPIVA米国スコアカード2025年末版によると、米国大型株ファンドがS&P500を下回った割合は2025年単年で約79%でした。5年では約87%、10年では約90%、15年・20年では約94%にのぼります。

年別で見ると、2022年（市場急落の年）は約51%と最も低い数字でしたが、2023年には60%、2024年には65%、そして2025年には79%と年々厳しくなっています。プロが最も健闘しやすいのは、市場が急落する局面でリスク管理能力を発揮できるときです。しかし平常時には、コストや情報効率の壁を乗り越えることが難しい状況が続いています。

日本とアメリカで数字は異なるものの、「長期になるほどアクティブファンドがベンチマークを下回る割合が増える」という共通のパターンが見られます。これはどちらか一方の市場特有の現象ではなく、投資信託業界全体に共通する構造的な問題を示しています。

https://www.spglobal.com/spdji/en/research-insights/spiva/

# なぜアクティブは長期で勝てないのか

多くの方が不思議に思うかもしれません。プロのファンドマネージャーが、経済・企業を徹底的に分析しても、なぜ市場平均に勝てないのでしょうか。その理由は複数あります。

**理由1：コストの壁**

最も根本的な理由はコストです。一般的なアクティブファンドの運用管理費用は年間1〜2%程度です。対してインデックスファンドは年間0.05〜0.1%程度にすぎません。

市場全体のリターンが年7%だとすると、インデックスファンドは6.9%前後のリターンが得られますが、アクティブファンドは市場平均と同等のパフォーマンスを上げても5〜6%しか残りません。コストを回収した上でさらに上回るには、常に市場に勝ち続けなければなりません。

**理由2：シャープの算術**

ノーベル経済学賞受賞者のウィリアム・シャープが提唱した考え方があります。アクティブ運用者全員の合計リターンは、コストを引く前の時点では市場平均と等しくなります。なぜなら、全てのアクティブ投資家が市場全体を構成しているからです。その後、手数料を差し引くと、アクティブ運用者全体の平均リターンは必ず市場平均を下回ります。

つまり、全アクティブファンドの平均がインデックスに負けることは、数学的に避けられません。

**理由3：市場効率性の向上**

AIや高速コンピュータを駆使した機関投資家の参入により、市場に出る情報は瞬時に株価へ反映されるようになっています。以前は「情報収集力」でアドバンテージを得られましたが、現代では個人・機関を問わずほぼ同じタイミングで情報を入手できます。このため、純粋な情報優位による超過リターンを得ることが、過去より格段に難しくなっています。

**理由4：過去の好成績が持続しない**

一時期に優れた成績を残したファンドが、その後も高いパフォーマンスを維持する保証はありません。好成績が実力によるものか、単なる運によるものかを判別することは非常に困難です。実際、短期で上位に入ったファンドが翌期も上位に残る確率は、統計的にランダムに近いことが複数の研究で示されています。

**理由5：ファンドマネージャーの移動**

優秀な人材ほど転職や独立をしてしまい、特定のファンドに長く留まりません。過去の好成績を支えた人物がいなくなれば、そのファンドの将来の成績も変わる可能性があります。

# コストの差が30年でどう変わるか

「年1%の差なんて大したことない」と思う方も多いかもしれません。しかし複利の力を考えると、この差は30年でとてつもない金額の差になります。

具体的に計算してみましょう。市場全体のリターンを年7%と仮定します。

インデックスファンド（運用コスト0.1%）の実質リターンは約6.9%です。アクティブファンド（運用コスト1.5%）の実質リターンは約5.5%となります。

この前提で100万円を30年間運用すると、次のような結果になります。インデックスファンドでは約740万円（実質6.9%複利）、アクティブファンドでは約500万円（実質5.5%複利）、その差額は約240万円にのぼります。

最初の投資額が100万円で、30年間追加投資なしの試算でこれだけの差が生まれます。毎月積み立てを行う場合は、この差はさらに大きくなります。

例えば、毎月3万円を30年間積み立てた場合、インデックスファンドでは資産が大きく膨らむのに対して、アクティブファンドでは数百万円規模の差が生じることもあります。

2026年時点の実際のインデックスファンドを見ると、楽天・プラス・オールカントリーは年0.05610%、eMAXIS Slim 全世界株式（オールカントリー）は年0.05775%というコストです。これらはアクティブファンドの典型的なコストの20〜30分の1以下です。

「コストは確実にかかるリターンのマイナス」という事実は、どのような市場環境でも変わりません。

# 2025年の例外：日本大型株がプロに有利だった理由

ここで一つ興味深いデータを取り上げます。2025年に限っていえば、日本大型株の分野ではアンダーパフォームの割合が約49%と、2017年以来最も低い水準でした。これは裏を返せば、約51%のファンドがベンチマークを上回ったことを意味します。珍しくプロが勝ち越した年でした。なぜこの年だけ違ったのでしょうか。

最大の理由は、「銘柄間ディスパージョン（ばらつき）」が過去10年で最大級だったからです。2025年の日本株市場では、不動産セクターが約40.7%、金融セクターが約35.3%という突出した上昇を記録する一方、ヘルスケアなど他のセクターは低迷しました。

つまり、上がる銘柄と上がらない銘柄の「差」がいつもより格段に大きかったのです。このような環境では、どの銘柄を選ぶかという「銘柄選択力」が発揮されやすくなります。指数全体を保有するインデックスファンドは、上がらなかった銘柄も同じ比率で保有しているため、上手に銘柄を絞ったアクティブファンドに負けるケースが増えました。

ただし、この一年の結果が長期トレンドを変えるわけではありません。日本大型株の10年成績では依然として83%のファンドがアンダーパフォームし、15年では80%がアンダーパフォームしています。「たまたま有利な環境が1年続いた」という解釈が妥当です。

このことは重要な教訓を示しています。「特定の年に良い成績を出したアクティブファンドがあっても、それが長期の優位性を意味するとは限らない」ということです。

# サバイバーシップバイアス（生存者バイアス）

「アクティブファンドの成績は、実は思っているより悪い」という事実を理解する上で、サバイバーシップバイアスという概念がとても重要です。

サバイバーシップバイアスとは、「生き残ったもの」だけを見て全体の傾向を判断してしまう認知の歪みのことです。投資信託の世界では、成績不振で清算・合併されたファンドが統計から除外されてしまうことで起こります。

例えば、2025年の1年間だけで、全アクティブファンドの約8%が清算・合併によって消えました。消えたファンドは当然ながら成績が振るわなかったものが大半です。これらを計算に含めないと、残ったファンドだけの「生き残り組」の平均成績が算出され、実際よりも良く見えてしまいます。

10年・20年と期間が長くなるほど、この問題はより深刻になります。20年前に存在したアクティブファンドの多くはすでに消えており、現在残っているのはその中でも比較的成績が良かったものが中心です。したがって、サバイバーシップバイアスを補正しないと、アクティブファンドの長期成績は現実より大幅に良く見えてしまいます。

SPIVAがこのバイアスを補正しているのは、公正な比較を行う上で非常に重要です。消えたファンドを含めたデータだからこそ、10年・15年で80〜100%がアンダーパフォームという数字が出てくるのです。

このバイアスを知ると、ランキングや広告で「当ファンドは10年で市場平均を上回りました」という文句を見たときに、別の視点から考えることができます。そのファンドが属していたカテゴリで、同時期に何%のファンドが消えたか。残った中での比較ではないか。そうした点に注目することが大切です。

# よくある疑問（FAQ）

**Q1. インデックスファンドなら損しないのですか？**

いいえ、そんなことはありません。インデックスファンドは株価指数の値動きに連動するため、市場全体が下落すれば同じように下落します。例えば、2008年のリーマンショック時には世界の株式市場が大幅に下落し、インデックスファンドも50%前後の値下がりを経験しました。

インデックスファンドが優れているのは「損をしない」からではなく、「同じリスクを取るなら、コストが低い分だけリターンが多く残りやすい」からです。長期投資においてはその差が積み重なり、大きな差を生みます。

**Q2. アクティブファンドが良い年もあるのに、なぜインデックスを選ぶのですか？**

確かに一部のアクティブファンドは特定の年に市場を上回ります。問題は、どのファンドが来年も勝ち続けるかを事前に予測することが非常に難しいという点です。

今年トップクラスのファンドが来年も上位を維持する確率は、統計的にランダムに近いことが示されています。インデックスファンドは「次に何が上がるかを当てる」必要がなく、市場全体の成長を丸ごと受け取る仕組みです。

**Q3. NISAではインデックスファンドとアクティブファンド、どちらが多いですか？**

新NISA制度でつみたて投資枠の対象となっているファンドのうち、インデックスファンドが採用される比率が高くなっています。2024年12月末時点で新NISA口座数は約2,559万口座に達しており、つみたて投資枠での利用ではインデックス型が約65.5%を占めています。低コストであることがNISAの税制優遇効果を最大化しやすいため、自然とインデックスファンドへの流入が多くなっています。

**Q4. 日本の投資信託市場でもインデックスが主流になっていますか？**

はい、急速に変わっています。2026年2月末時点で公募投資信託の純資産総額は約329兆8,023億円と過去最高を更新しており、そのうち株式投資信託ではインデックス型が約64.4%を占めています。例えばeMAXIS Slim 全世界株式（オールカントリー）は「Fund of the Year 2025」インデックス部門で7年連続1位を獲得するなど、インデックス型の人気が定着しています。

**Q5. アクティブファンドは完全に不要なのでしょうか？**

全ての状況でそうとは言い切れません。特定の資産クラスや市場（例えば流動性の低い新興国の小型株など）では、情報優位を持つ専門家が優位性を発揮しやすい場合もあります。また、相続対策や特定の税務戦略、あるいはマーケットニュートラル戦略など、インデックスでは実現できない運用目的のために利用される場面もあります。しかし、一般的な長期資産形成の目的では、データはインデックスファンドの優位性を強く示しています。

# 注意点・リスク

本記事で紹介したSPIVAのデータは過去の実績であり、将来の結果を保証するものではありません。以下の点を必ず念頭に置いてください。

インデックスファンドも市場全体が下落した場合は同様に下落します。株式市場には短期的な大幅な変動が常に伴います。2020年のコロナショック、2022年の金利急騰による株式・債券の同時下落など、過去にも予測不能な急落が繰り返されてきました。

また、本記事で取り上げたデータは主に株式ファンドに関するものです。債券ファンドや不動産ファンドなど、他の資産クラスでは事情が異なる場合があります。

投資判断は個人の年齢・収入・リスク許容度・投資目的などによって大きく異なります。本記事はあくまでも一般的な情報提供を目的としており、個別の投資アドバイスではありません。具体的な投資判断については、必要に応じてファイナンシャルアドバイザーなどの専門家に相談することをお勧めします。

さらに、本記事で取り上げたコストの数字や制度（NISAなど）は変更される可能性があります。最新情報は各金融機関や金融庁のウェブサイトでご確認ください。

# まとめ

SPIVA2025年末版のデータが示した結論は明確です。日本でもアメリカでも、長期になればなるほど、アクティブファンドがベンチマーク（市場平均）を下回る割合は増えていきます。日本大型株を除く5カテゴリで80%以上がアンダーパフォームし、グローバル・国際・新興国株式では10年・15年で100%がアンダーパフォームしました。

アクティブファンドが長期で勝てない主な理由はコストと市場効率性です。年1〜2%のコスト差が30年で積み重なると、100万円の元本に対して240万円以上の差になることもあります。

もちろん、2025年の日本大型株のように特定の環境でアクティブが有利になる年もあります。また、アクティブファンドが全ての場面で無意味というわけでもありません。しかし、一般的な長期資産形成の目的においては、SPIVAが20年以上にわたって示し続けてきた事実は明確です。

「コストが低く、市場全体に分散投資できるインデックスファンドを長期保有する」というシンプルな戦略が、多くの投資家にとって合理的な選択肢の一つであることが、データによって繰り返し裏付けられています。
