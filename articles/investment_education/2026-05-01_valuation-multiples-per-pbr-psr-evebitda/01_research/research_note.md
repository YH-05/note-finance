## 1. PER（株価収益率）

### 定義・計算式

PER（Price Earnings Ratio）= 株価 ÷ 1株当たり純利益（EPS）
または = 時価総額 ÷ 当期純利益

「株価が利益の何倍で取引されているか」を示す。PERの逆数（EPS÷株価）を「益利回り」と呼び、株の会計上の利回りを意味する。

### 適切な水準（日本・米国）

**日本（日経平均・TOPIX）:**
- 長期的な経験則として、日経平均・TOPIXは**14〜16倍**が「割安でも割高でもない」適正水準とされてきた（ニッセイ基礎研究所の研究）
- 2025年5月時点: 日経平均 **予想PER 約19.77倍**、プライム全銘柄 **約18.92倍**（日本経済新聞データ）
- TOPIXの長期平均（2005〜2025年）: **約13.9倍**（J.P. Morgan Asset Management）
- グロース市場全銘柄は**41〜68倍**と高水準（成長期待を反映）

**米国（S&P500）:**
- S&P500の過去10年平均: **約19.2倍**
- 2024〜2025年水準: **20〜25倍**（AI・テクノロジー銘柄主導で高め）
- マグニフィセント7の平均PER: **約30.7倍**

**業種別（日本・2025年2〜3月時点）:**

| 業種 | PER目安 |
|------|---------|
| 医薬品 | 37〜39倍 |
| 電気機器 | 26〜27倍 |
| 精密機器 | 22〜25倍 |
| 食料品 | 18〜19倍 |
| 輸送用機器（自動車等） | 9〜10倍 |
| 鉄鋼 | 6〜7倍 |
| 石油・石炭 | 7〜8倍 |

### 長所
- 最もシンプルで直感的に割安・割高を判断できる
- 「元を取るのに何年かかるか」の目安として使いやすい
- 多くの情報端末で即座に確認できる
- 同業他社比較・過去比較の両方に使える

### 短所
- **赤字企業には使えない**（マイナスのEPSでは計算不能）
- 一時的な特別利益・損失に結果が左右される
- 業種によって適正水準が大きく異なるため、業種をまたいだ比較は難しい
- 財務構造（借入の多寡）の影響を受ける

### 使いやすいセクター
- 収益が安定した成熟企業全般（食品、消費財、小売など）
- 利益成長が読みやすい業種（景気敏感でない安定成長企業）

### 使いにくいセクター
- 赤字のIT系スタートアップ、バイオ、グロース系
- 景気変動が大きな素材・鉄鋼・海運
- 特別損益が多い企業

## 2. PBR（株価純資産倍率）

### 定義・計算式

PBR（Price Book-value Ratio）= 株価 ÷ 1株当たり純資産（BPS）
または = 時価総額 ÷ 純資産（自己資本）

「株価が企業の帳簿上の資産の何倍で評価されているか」を示す。PBRが1倍ならば、株価が解散価値と等しい状態。

- **重要な分解式**: PBR = PER × ROE（自己資本利益率）

### 東証のPBR1倍割れ問題（2023年以降の動向）

**2023年3月31日 東証の歴史的要請:**
- 東証はプライム・スタンダード市場の全上場企業に「資本コストや株価を意識した経営」を要請
- 当時、プライム市場上場企業の約**半数がPBR1倍割れ**（2022年7月時点）

**2025年7月時点の改善状況:**
- プライム市場のPBR1倍割れ企業: **44%**（2022年時点の50%から改善、-6pt）
- スタンダード市場: **59%**（-5pt）
- プライム市場のROE8%未満企業: **43%**（-4pt改善）

**現在の日本市場PBR水準（2025年5月時点）:**
- 日経平均: **1.81倍**
- プライム全銘柄: **1.67倍**
- グロース全銘柄: **3.49倍**

### 長所
- 会計上の「解散価値」と比較できる下値支持の目安になる
- 利益が出ていない企業にも適用できる（純資産がプラスなら計算可能）
- 資産の裏付けを重視するバリュー投資に適している

### 短所
- 帳簿価額（簿価）ベースのため、時価と乖離することが多い
- ブランド・特許・人的資本など**無形資産が大きい企業**では過小評価になる
- PBRだけ見ても「なぜ低いか」がわからない。ROEと合わせた分析が必須
- 「PBR1倍割れ=必ず割安」ではなく、稼ぐ力が低い（低ROE）ために低評価されているケースも多い

### 使いやすいセクター
- **金融業（銀行・保険）**: 自己資本が評価の中心
- **製造業・重厚長大産業**: 有形資産が多い企業（鉄鋼・電力・建設等）
- **不動産**: 土地・建物が資産の中心

## 3. PSR（株価売上高倍率）

### 定義・計算式

PSR（Price to Sales Ratio）= 時価総額 ÷ 売上高
または = 株価 ÷ 1株当たり売上高

「時価総額が年間売上高の何倍か」を示す。利益ではなく**売上高**が分母のため、赤字企業でも計算できる。

### SaaS・成長株での活用

- SaaS企業、成長フェーズのスタートアップの評価に有効
- 「今は赤字でも売上が急成長している企業」を評価する際に有効

**マネーフォワード（2017年上場時）の実例:**
- 想定時価総額: 243.1億円
- 前期売上高15.4億円 → PSR 15.78倍
- 今期予想売上高26.8億円 → PSR 9.07倍
- その後2021年に時価総額は18.6倍に成長

### 長所
- **赤字企業・債務超過企業にも使える**（売上高がプラスなら計算可能）
- 売上高は会計処理の影響を受けにくく、比較的操作されにくい
- 成長ステージの企業の「成長の勢い」を評価できる

### 短所
- **利益率の低い業種（薄利多売の小売・製造等）では割安に見えすぎる**
- 売上が伸びても利益化できなければ意味がない
- 成熟・黒字企業には他の指標（PER等）の方が適切

### 適切な水準の目安

| PSR水準 | 一般的な判断 |
|---------|-------------|
| 0.5倍以下 | 割安の可能性（ただし利益率の低さに注意） |
| 1〜10倍 | 成長企業の標準的な範囲 |
| 20倍以上 | 割高傾向（高い成長性が織り込まれている） |
| 45倍超 | 極めて割高（Zoom 2020年3月の実例）|

## 4. EV/EBITDA

### 定義・計算式

**EV（企業価値）** = 時価総額 + 有利子負債 - 現預金等

**EBITDA** = 営業利益 + 減価償却費
または = 当期純利益 + 法人税等 + 特別損益 + 金融費用 + 減価償却費

**EV/EBITDA倍率** = EV ÷ EBITDA

「企業全体を買収したとして、何年でその投資を回収できるか」を示す直感的な指標。

### 業種別 EV/EBITDA 倍率（2024年 日本上場企業・中央値）

| 業種 | 中央値（2024年） |
|------|----------------|
| 全業種 | **7.5倍** |
| 情報・通信業 | 9.1倍 |
| 不動産業 | 10.5倍 |
| 小売業 | 9.0倍 |
| サービス業 | 8.2倍 |
| 食料品 | 8.3倍 |
| 輸送用機器 | 4.1倍 |
| 鉄鋼 | 4.8倍 |

**M&A実績倍率（日本M&Aセンター）:**
- 飲食業界: 平均6.2倍
- 金属・プラスチック関連: 平均5.7倍
- 一般機械・電気機器: 平均5.3倍

### 長所
- **国や会計基準が異なる企業間の比較に最も適している**
- 減価償却方法の違いを排除できる
- 資本構成（負債の多寡）の影響を受けない
- 「投資回収期間」として直感的に理解しやすい

### 短所
- **金融機関（銀行・保険）には使えない**
- **設備投資が多い製造業では正確さが下がる**
- 計算が比較的複雑
- 個人投資家がリアルタイムで確認しやすい情報端末は少ない

## 5. 指標の比較・使い分け

### 4指標の概要比較

| 指標 | 何を測るか | 計算の分母 | 赤字企業への適用 | 主な利用場面 |
|------|-----------|------------|-----------------|------------|
| PER | 利益に対する株価水準 | 純利益 | 不可 | 成熟黒字企業の割安判断 |
| PBR | 資産に対する株価水準 | 純資産 | 可（純資産プラスなら） | 資産重視の評価、バリュー投資 |
| PSR | 売上に対する株価水準 | 売上高 | 可 | 成長株・赤字スタートアップ |
| EV/EBITDA | 企業全体価値に対する収益力 | EBITDA | 可（EBITDAがプラスなら） | M&A・クロスボーダー比較 |

### 使い分けガイド（シーン別）

| シーン | 推奨指標 | 理由 |
|--------|---------|------|
| 日本の成熟企業（トヨタ、任天堂等）を評価 | PER + PBR | 利益・資産の両面から評価 |
| 金融銘柄（銀行・保険）を評価 | PBR | EVが定義できないためEV/EBITDAは不適 |
| 赤字のIT・SaaS企業を評価 | PSR + EV/EBITDA | PERが使えないため売上・EBITDA基準で |
| M&Aで買収対象を比較・評価 | EV/EBITDA | 資本構成・税制の違いを排除できる |
| 米国株と日本株を横断比較 | EV/EBITDA | 会計基準の違いを吸収できる |
| 利益が出ていないスタートアップのIPO | PSR | 唯一使える収益指標 |
| 不動産・インフラ企業 | PBR + EV/EBITDA | 資産価値と収益力の両面で |

### 初心者が最初に覚えるべき順序

1. **まずPER**: 最もシンプルで使用頻度が高い。「15〜20倍が日本株の目安」を覚える
2. **次にPBR**: 東証改革（2023年〜）で注目度が急上昇。「1倍割れ」「ROEとの関係」を理解する
3. **その次にPSR**: 成長株・グロース投資に興味が出たら。「赤字企業に使う指標」として理解する
4. **最後にEV/EBITDA**: M&A・企業買収や海外株に興味が出たら。「クロスボーダー比較の王様」として
