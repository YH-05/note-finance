## テーマ1: 72の法則の正体

### 基本公式
- **使い方**: 72 ÷ 年利(%) ≈ 元本が2倍になる年数
- **例**: 年利5% → 72÷5 = 14.4年
- **逆算**: 72 ÷ 年数 ≈ 2倍に必要な年利率

### なぜ72なのか？（数学的導出）

正確な倍増年数は対数関数で計算される：
```
t = ln(2) / ln(1 + r/100)
```

ここで **ln(2) ≈ 0.693**（連続複利なら69.3の法則が正確）

年1回複利の場合、r≒8%で補正係数f(8)≈1.039を乗じると：
```
t ≈ 69.3 × 1.039 / r ≈ 72 / r
```

**72が選ばれる理由**：
1. 数学的に年利8%周辺で最精度
2. 約数が多い（1,2,3,4,6,8,9,12）→暗算しやすい
3. 連続複利なら69.3、日次複利なら69〜70が正確

### 精度の限界
- 最精度範囲: **年利6〜10%**（誤差±5%以内）
- 低金利（2%以下）は69.3の方が正確
- 高金利（20%超）は78の方が正確
- **E-M Rule**（より精度高い）: t = (69.3/r) × (200/(200-r))

### 応用法則
| 法則 | 用途 | 計算式 |
|-----|------|--------|
| 72の法則 | 一括投資で2倍 | 72 ÷ 利回り = 年数 |
| 126の法則 | **積立投資**で2倍 | 126 ÷ 利回り = 年数 |
| 115の法則 | 一括投資で3倍 | 115 ÷ 利回り = 年数 |

出典：[アセットマネジメントOne](https://www.am-one.co.jp/warashibe/article/fuyasu-20250318-1.html)

## テーマ2: ボラティリティ減衰（Volatility Drag）の正体

### 直感的な理解

「算術平均リターン0%でも複利では損をする」という逆説：

```
例：+10%/-10%が交互に続く相場
→ 算術平均 = (10% - 10%) / 2 = 0%
→ 1往復後: 100 × 1.10 × 0.90 = 99 （-1%の損失）
→ N往復後: 100 × 0.99^N → 指数関数的に減衰
```

```
例：+60%/-40%
→ 算術平均 = (60% - 40%) / 2 = 10%（「年10%のリターン」に見える）
→ 実際: 100 × 1.60 × 0.60 = 96 （2年で-4%の損失）
→ 幾何平均（CAGR）= √0.96 - 1 ≈ -2.02%
```

### 数式（ボラティリティドラッグの近似）

```
幾何平均 ≈ 算術平均 - σ²/2
```

- **σ**: 標準偏差（ボラティリティ）
- **σ²**: 分散（Variance）
- **σ²/2**: ボラティリティドラッグ

伊藤の補題（連続時間モデル）による厳密な導出：
```
d(ln S_t) = (μ - σ²/2)dt + σdW_t
→ 長期期待成長率 = μ - σ²/2
```

### 実データ（S&P500の実例）

**1926〜2023年（97年間）の米国株式市場**：
- 算術平均: **12.01%**
- 幾何平均（CAGR）: **10.12%**
- ボラティリティドラッグ: **約1.89%**
- 標準偏差（σ）: 19.8% → σ²/2 = 19.8²/2 ≈ 1.96%

[出典: Moontower.ai - Geometric vs Arithmetic Mean In The Wild](https://blog.moontower.ai/geometric-vs-arithmetic-mean-in-the-wild/)

**Kitcesの分析データ（S&P500）**：
- 算術平均: 8.75%
- 標準偏差: 18.86%、分散: 3.56%
- 予測幾何平均: 8.75% - 3.56%/2 = **6.97%**
- 実際の幾何平均: **6.94%**（非常に高精度な近似）

**債券（Barclays Aggregate）との比較**：
- 算術平均: 4.39%、標準偏差: 3.12%、分散: 0.10%
- ドラッグ: たった**0.05%**
- 株式に比べてボラティリティが低いためドラッグが極小

[出典: Kitces.com - Volatility Drag: How Variance Drains Investment Returns](https://www.kitces.com/blog/volatility-drag-variance-drain-mean-arithmetic-vs-geometric-average-investment-returns/)

### 含意

- 広告や資料に書かれた「年率リターン」は**算術平均（過大評価）**の場合が多い
- 投資家が実際に体験するリターンは**幾何平均（実際の資産成長率）**
- **ボラティリティが高い資産ほどドラッグが大きい**（レバレッジETFで特に顕著）

## テーマ3: 年率リターンの罠（コスト・インフレ・税金）

### コストの複利効果

**ケース: 30年間・グロス年7%のリターン**
- コスト差1%追加につき最終資産が**約20〜25%減少**
- インデックスETF（年0.1%未満）vs アクティブ投信（年1〜2%）の差
- 保険型商品（変額年金等）は年2.5〜4%のコスト→税メリットを超えるコスト漏洩

逆複利効果の数値例：
```
元本100万円 × 年利6% × 30年:
- コスト0%: 574万円
- コスト1%: 432万円 (25%減)
- コスト2%: 324万円 (44%減)
```

[出典: Maclear.ch - 投資手数料がリターンを逆複利で削る仕組み](https://www.maclear.ch/ja/blog/how-fees-compound-against-your-returns)

### インフレの侵食
- 「名目リターン7%」でもインフレ3%なら「実質リターン4%」
- 「実質倍増年数」= 72 ÷ 実質利回り = 72 ÷ 4 = **18年**
- 名目だけで考えると15年早まったように錯覚する（72÷7≈10.3年）

### 税金の罠
- 日本の金融課税: 20.315%（利益・配当金）
- 課税口座で毎年分配金を受け取ると「利益→税引き後→再投資」となり複利効率が低下
- NISA非課税口座での複利 vs 課税口座での複利：長期では大きな差

### NISAの効果（複利への影響）
- 非課税で再投資されるため**税引き前リターン全額が複利ベース**に
- 年利5%・30年の場合: NISA（5%全額複利）vs 課税口座（5%×0.7969の実質複利）
  - 差は長期になるほど拡大

## テーマ4: 複利の基本メカニズム

### 単利 vs 複利の比較

**例: 元本100万円・年利10%・5年間**
- 単利: 100万 + 10万×5 = **150万円**
- 複利: 100万 × (1.10)^5 = **161.05万円**
- 差額: 11万円

計算式:
- 複利: FV = PV × (1 + r)^n
- 単利: FV = PV × (1 + r×n)

### 長期で爆発的成長
- 年利7%・10年: 2.0倍
- 年利7%・20年: 3.9倍
- 年利7%・30年: 7.6倍

（J字カーブ：前半は緩慢→後半に急加速）

### アインシュタイン伝説について
「複利は人類最大の発明だ」という言葉はアインシュタインに帰されるが、**出典は見つかっていない**。松井証券コラムでも確認済み。ただしその概念の重要性は事実。

## 記事構成案（ドラフトへの引き継ぎ）

### 想定読者
- 投資初心者〜中級者
- 「複利効果がすごい」という言説の**本当の意味**を理解したい人

### 記事の核心メッセージ
1. 「72の法則」は便利なツールだが**近似であり限界**がある
2. 「平均年率○%」という数字は**実際の資産増加率（幾何平均）を過大評価**している
3. ボラティリティが高いほど「宣伝されたリターン」と「実際に手元に残るリターン」の乖離が大きい
4. コスト・インフレ・税金という3つの「複利の天敵」を理解すれば、本当に資産が増える投資選択ができる

### 推奨構成
1. **イントロ**：「複利の魔法」という幻想に乗っかって失敗するパターン
2. **72の法則の正体**：なぜ72？ln(2)=0.693から72への道のり。精度の限界も正直に
3. **算術平均 vs 幾何平均（ボラティリティの罠）**：+10%/-10%の衝撃実験。S&P500の実データ
4. **年率リターンの3つの罠**：コスト複利、インフレ侵食、税金の利益漏洩
5. **正しく複利を使う**：低コスト・NISA・長期保有の組み合わせ
