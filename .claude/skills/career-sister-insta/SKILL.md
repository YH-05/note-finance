# キャリアお姉さん Instagram ライタースキル

@career_sister の Instagram 投稿に特化したスキル。
カルーセル画像とキャプションの品質基準・構造を規定する。

## プラットフォーム制約

| 項目 | 規定 |
|------|------|
| キャプション文字数 | **2,200字以内** |
| キャプション目安 | 500-1,500字 |
| カルーセル枚数 | 5-10枚 |
| 1スライドの文字数 | 30-60字（大きめの文字で読みやすく） |
| ハッシュタグ | キャプション末尾に5-10個 |
| 画像フォーマット | 1080x1350px（4:5縦長推奨） |

## ペルソナ要約

キャリアお姉さんのペルソナはThreadsと共通。詳細は `career-sister-threads` スキルを参照。

**Instagram特有の注意点**:
- カルーセルは「保存率」が重要指標。保存したくなる実用的な内容にする
- 1枚目はフック（スクロールを止める力）
- テキストは大きく、1スライド1メッセージ

## 声 — 口調ルール

Threads同様の姉御肌タメ口を維持。カルーセルのテキストでは以下を追加で意識:

- 短文。1スライド1メッセージ
- 体言止め多用（スライドでは効果的）
- 「〜なのよ」「〜だったりするんだよね」は文字量が多いので避ける
- キャプションではThreads同様の口調を維持

## NG リスト

Threads共通に加えて:

| NG | 理由 |
|----|------|
| テキストびっしりのスライド | 読みにくい。1スライド1メッセージ |
| フォントサイズが小さすぎる | スマホで読めない |
| 「詳しくはプロフリンクから」の連発 | 宣伝感が出る |

## カルーセル構成テンプレート

### 型IG1: Tips系カルーセル（最も汎用的）

| スライド | 内容 | 文字数目安 |
|---------|------|----------|
| 1枚目 | **フック**。「知らないと損する」「これだけ見て」系 | 20-30字 |
| 2枚目 | 問題提起。「こんな経験ない？」 | 30-50字 |
| 3-7枚目 | Tips本体。1枚1ポイント | 各30-60字 |
| 8枚目 | まとめ。「つまりこういうこと」 | 30-50字 |
| 9枚目 | CTA。「保存して見返してね」「他の投稿もチェック」 | 20-30字 |

### 型IG2: ストーリー系カルーセル

| スライド | 内容 | 文字数目安 |
|---------|------|----------|
| 1枚目 | **フック**。「28歳で転職した話」 | 15-25字 |
| 2-3枚目 | 状況説明 | 各30-50字 |
| 4-5枚目 | 転機・困難 | 各30-50字 |
| 6-7枚目 | 学び・気づき | 各30-50字 |
| 8枚目 | 結論。読者へのメッセージ | 30-50字 |
| 9枚目 | CTA | 20-30字 |

### 型IG3: データ系カルーセル

| スライド | 内容 | 文字数目安 |
|---------|------|----------|
| 1枚目 | **フック**。「2026年の転職市場、知ってる？」 | 20-30字 |
| 2枚目 | 注目データ①（数字を大きく） | 数字 + 一言 |
| 3枚目 | 注目データ②（数字を大きく） | 数字 + 一言 |
| 4-6枚目 | データの解説（噛み砕いて） | 各30-50字 |
| 7枚目 | 「つまりこういうこと」 | 30-50字 |
| 8枚目 | 行動提案 | 30-50字 |
| 9枚目 | CTA | 20-30字 |

## キャプション構成

```
[1行目: フック。スライドの要約を別角度で]

[本文: スライドの補足。自分の経験を交えて3-5段落]

[CTA: 「保存して見返してね」「気になったらコメントで教えて」]

[ハッシュタグ: 5-10個]
```

## ハッシュタグ

| カテゴリ | ハッシュタグ |
|---------|------------|
| メイン | #転職 #キャリア #転職活動 |
| ミドル | #転職成功 #年収アップ #職務経歴書 #面接対策 |
| ニッチ | #大手からベンチャー #20代転職 #30代転職 #異業種転職 |
| エンゲージ | #転職あるある #社会人あるある |

## カルーセル選定優先度

Threadsの投稿型をInstagramに展開する場合の優先度:
1. 型4（データ→意外性）→ 型IG3
2. 型2（あるある→解決策）→ 型IG1
3. 型1（結論→ストーリー→問いかけ）→ 型IG2
4. 型3（失敗談→学び）→ 型IG2
5. 型5（市場データ→インサイト）→ 型IG3

## 品質チェックリスト

- [ ] カルーセル5-10枚の構成になっているか
- [ ] 1枚目にスクロールを止めるフックがあるか
- [ ] 1スライド1メッセージ（30-60字以内）か
- [ ] キャプションが2,200字以内か
- [ ] ハッシュタグが5-10個ついているか
- [ ] キャリアお姉さんの口調（姉御肌タメ口）になっているか
- [ ] NGワードを使っていないか
- [ ] 最終スライドにCTAがあるか（保存・コメント誘導）
- [ ] 他ペルソナの口調と混同していないか

## 一貫性チェック

career-sister-threads と同一。7項目を確認すること。
