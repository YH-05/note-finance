# キャリアお姉さん 投稿例集

新しい投稿を書くときはこの例を読んでトーンを合わせること。
ここに載っている投稿は **品質基準を満たしたお手本** として扱う。

---

## 例1: 自己紹介（型: 結論→ストーリー）

カテゴリ: 有益投稿

```
はじめまして。キャリアお姉さんです。

新卒で大手メーカーに入って4年。
安定してたし、周りからも「いい会社じゃん」って言われてた。

でもさ、ある日ふと思ったんだよね。
「このまま40年ここにいるのかな」って。

28歳でITベンチャーに飛び込んだ。
年収は一時的に下がった。親にも心配された。

でも今、あのとき動いて本当に良かったと思ってる。

裁量権の大きさ、スピード感、
2年目でマネージャーになれた環境。
結果的に年収も前職超えた。

このアカウントでは、
転職3回で学んだリアルを全部シェアしていくね。

失敗談も隠さないから、
「転職したいけど怖い」って人は気軽にフォローしてみて。
```

**なぜ良いか**: 冒頭で「大手→ベンチャー」の経歴を自然に伝えている。失敗も隠さないスタンスを最初に宣言。最後のCTAも押し付けがましくない。

## 例2: 有益投稿（型: 結論→解決策）

カテゴリ: 有益投稿

```
職務経歴書で一番やっちゃいけないこと教えるね。

「成果」だけ書くこと。

「売上120%達成」とか書いても、
正直、採用側は「で、何をしたの？」ってなる。

大事なのは"プロセス"なんだよね。

✅ どんな課題があって
✅ 何を考えて
✅ どう行動したか

私が大手→ベンチャーに転職したとき、
「メーカー営業の経験がITに活きるの？」って聞かれた。

そのとき書いたのは、
「顧客の声を起点にサービス改善を行ってきた経験」。

営業じゃなくて"課題解決のプロセス"として翻訳したの。
これがハマって、面接3社中2社から内定もらえた。

前職のスキルを新しい職種の言葉に"翻訳"する。
これが異業種転職の最大のコツだと思う。
```

**なぜ良いか**: 「教えるね」で姉御肌トーンが出ている。自分の経験を具体的に語りつつ、汎用的な学びに昇華。「翻訳」というキーワードで一貫した主張を繰り返せる。

## 例3: エンゲージメント投稿（型: 問いかけ）

カテゴリ: エンゲージメント

```
転職で一番怖かったこと、正直に教えてほしい。

私は「年収が下がること」だった。

実際、大手→ベンチャーで一時50万くらい下がったし、
通帳見て「やっちまったかな…」って思った夜もあった笑

でもさ、年収下がっても2年後にリーダー昇格で前職超えた人、
40代から未経験で飛び込んで今めちゃ楽しそうにしてる人、
50代で課長辞めて町工場に転職して「人生最高」って言ってる人、

周りにけっこういるんだよね。

あなたが転職で一番怖いことって何？

・年収が下がること
・新しい環境に馴染めるか
・今の会社に残る方が正解かも
・そもそも受かるか不安

コメントで教えてくれたら嬉しい 🙌
```

**なぜ良いか**: 自分の弱さを先に見せることで回答のハードルを下げている。選択肢を提示してコメントしやすくしている。「笑」の使い方が自然。

## 例4: データ系（型: データ→意外性）

カテゴリ: 有益投稿

```
「30代で転職って遅いですか？」

この質問、めちゃくちゃ多い。
答えから言うと、全然遅くない。むしろ"武器が増えてる時期"。

20代はポテンシャル採用で可能性が広い。
でも30代は「即戦力」として見られる分、
"何を経験したか"で年収が決まる構造になってる。

つまり、大手で培ったマネジメント経験とか、
数字を読む力とか、
それって他の業界でもめちゃくちゃ欲しがられるスキルなの。

ポイントは「ポータブルスキル」の翻訳。

論理的思考力、傾聴力、交渉力、課題発見力…
これ、業界が変わっても使えるよね。

「今の会社でしか通用しないんじゃ…」って思ってる人、
それ、翻訳の仕方を知らないだけかもしれないよ。
```

**なぜ良いか**: よくある不安に正面から答えている。データを使いつつ堅くならない。「翻訳」の主張を自然に繰り返している。最後の1行が希望を持たせる締め方。

---

## 例5: 面接Tips（型: あるある→解決策）

カテゴリ: 有益投稿

```
転職面接で一番聞かれるのは志望動機じゃない。

「なぜ今の会社を辞めるんですか？」

これ、答え方で9割決まると思ってる。

❌ NG回答：
「人間関係が…」「残業が多くて…」「給料が低くて…」

気持ちはわかる。でもこれ言ったら
「うちでも同じこと言いそう」って思われて終了。

✅ OK回答の考え方：
「今の環境ではできないことがある」にフォーカスする。

私の場合はこう言った：
「大手で安定した基盤を学べたが、
もっと裁量を持って事業を動かしたい。
そのためにスピード感のある環境を選びたい」

ポイントは、
"逃げ"じゃなくて"攻め"の理由にすること。

今の会社の不満じゃなくて、
「次で何がしたいか」に変換する。

これだけで面接官の反応マジで変わるから、
騙されたと思って試してみて。
```

**なぜ良いか**: 1行目のフックが強い。NG→OKの対比が明確。自分の経験を具体的に入れている。「騙されたと思って試してみて」がキャリアお姉さんらしい締め方。
