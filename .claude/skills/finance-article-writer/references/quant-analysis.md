# quant_analysis（クオンツ分析）

## 文字数

- **目標**: 8000-10000字
- **最低**: 8000字（これ未満は不可）
- **最大**: 10000字（これ超過は不可）

## 対象読者

中級者〜上級者。プログラミングや統計の基礎知識がある読者を想定する。シャープレシオ、最大ドローダウンなどの指標は説明不要。ただし独自の指標や手法を使う場合は定義を明示する。

## カテゴリ固有ルール

### バックテストの透明性

- 検証条件を全て明示する（期間、コスト仮定、スリッページ仮定）
- ルックアヘッドバイアス・サバイバーシップバイアスへの対処を記載する
- パラメータの選択根拠を説明する（過剰最適化の疑いを払拭）

### 再現可能性

- 戦略のロジックを他の人が再現できるレベルで記述する
- コードを公開する場合は GitHub リンクを掲載
- 使用ライブラリとバージョンを明記する

### ディスクレーマー（quant_analysis 固有）

テンプレートに示した通り、バックテスト固有の免責文を含む統合ディスクレーマーを記事末尾に1箇所だけ配置する。冒頭には入れない。

### フロントマター

```yaml
---
title: "{戦略名/分析タイトル}"
article_id: {article_id}
category: quant_analysis
strategy: {戦略名}
backtest_period: "{開始年-終了年}"
status: draft
---
```
