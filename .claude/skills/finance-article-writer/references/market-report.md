# market_report（週次市場レポート）

## 文字数

- **目標**: 3000-5000字
- **最低**: 3000字
- **最大**: 5000字

## 対象読者

中級者。週次で市場動向をチェックしている読者を想定する。基本的な市場用語の説明は不要。速報性と網羅性のバランスが重要。

## セクション構成テンプレート

```markdown
# {タイトル: 例「週次マーケットレポート 3/24-3/28」}

# 今週の市場サマリー
[300-500字: 主要指標の動き、最も重要なイベント。
 忙しい読者がここだけ読んでも価値がある内容にする]

# 株式市場

## 米国市場
[S&P 500, NASDAQ, DOW の週間動向]
- 週間騰落率
- 主要な値動きの要因
- セクター別動向（注目セクターをピックアップ）

## 日本市場
[日経平均、TOPIX の週間動向]

## その他注目市場（任意）
[欧州、新興国等で大きな動きがあった場合]

[金利動向、原油、金 等]

```

## カテゴリ固有ルール

### 速報性と正確性

- データは記事作成時点の最新値を使用する
- 「先週」「今週」などの相対表現は避け、具体的な日付範囲を使う
- 数値は小数点以下を統一する（指数は小数点以下2桁、為替は小数点以下2桁）

### サマリーの重要性

市場レポートは「今週の市場サマリー」が最も重要。忙しい読者はここしか読まない可能性がある。300-500字で以下を含める:
- 最も大きな市場変動とその要因
- 週を通じたトレンド（上昇基調/横ばい/下落基調）
- 翌週に向けた注目ポイント

### 数値の提示

- 週間騰落率は % で統一
- 前週比と年初来の両方を提示すると文脈がわかりやすい
- 重要な数値にはソースURLを埋め込む
