# CFP級記事 共通ルール

CFP（Certified Financial Planner）水準の品質を担保するための横断ルール。
将来の IFA 独立を見据え、顧客獲得につながる「専門家品質」のコンテンツを制作するための基準を定義する。

このルールは `meta.yaml` の `quality_tier: cfp_grade` が設定された記事に適用される。
`quality_tier: standard` の場合は適用されない。

---

## 1. 文字数と構造

### 文字数

- **目標**: 12000-15000字
- **最低**: 12000字（これ未満は不可）
- **最大**: 15000字（これ超過は不可）

### 必須セクション構成

```markdown
# {タイトル}

# はじめに
[600-900字: 記事の到達点・対象読者・前提知識を明示]

# 制度の全体像
[1500-2000字: 法令上の位置付け、関連条文、制度の沿革、対象範囲]

# 仕組みと計算式
[2000-2500字: 計算式の明示、構成要素の分解、数式の言葉での補足]

# データで見る実態
[1500-2000字: 公的統計を引用したファクト、近年の改正トレンド、図表]

# ペルソナ別シミュレーション
[2500-3500字: 3-4ケースのペルソナで具体計算を提示]

# よくある誤解と注意点
[1500-2000字: 一般に流布する誤解、業際規制での留意点、リスク]

# 実践チェックリスト
[800-1200字: 読者が今日から実行できる確認項目]

# まとめと次のステップ
[600-900字: 要点整理、関連トピックへの導線、相談先案内]

---

## 参考データソース
{使用した一次出典リスト}

---

{snippets/closing-greeting.md の全文}

---

{snippets/disclaimer.md の全文}
{snippets/not-tax-advice.md または snippets/not-insurance-recruitment.md の全文（該当時）}
```

## 2. 信頼性ランク S の新設

CFP級記事では **信頼性ランク S** を最上位として導入する。

| ランク | 該当ソース | 必要割合 |
|--------|-----------|---------|
| S（最高・一次出典） | 法令・通達・所管官庁の公式文書（厚労省・国税庁・金融庁・国交省・文科省等）、政府統計、公的機関の白書 | 50%以上 |
| A | 公的色の強い団体（日本年金機構、JASSO、生保協会、損保協会、JHF、東証、GPIF） | A+S で 70%以上 |
| B | 大手金融機関のレポート、シンクタンク（大和総研、ニッセイ基礎研、野村総研等） | B以下は30%以下 |
| C | 主要メディア（日経、Bloomberg、ロイター等） | 20%以下 |
| D | 個人ブログ・SNS | 使用不可 |

CFP級記事では **D ランクの使用は禁止**。C ランクは数値の確認用にのみ使用し、根拠としては必ず S/A ランクで裏付ける。

## 3. 計算式の必須要件

CFP級記事では、税額・給付額・保険料・住宅ローン返済額等の数値を扱う際、**計算式を必ず明示**する。

### 計算式の記述パターン

#### パターン1: 数式 + 言葉の補足

```markdown
退職所得控除額は次の式で求めます。

- 勤続20年以下: 40万円 × 勤続年数（最低80万円）
- 勤続20年超: 800万円 + 70万円 ×（勤続年数 − 20年）

つまり、勤続20年までは1年あたり40万円ずつ控除枠が積み上がり、20年を超えると1年あたり70万円に増額される構造です。
```

#### パターン2: 計算過程の段階表示

```markdown
【勤続38年・退職金2500万円のケース】

1. 退職所得控除額を計算
   800万円 + 70万円 ×（38年 − 20年） = 800万円 + 1260万円 = 2060万円

2. 退職所得を計算
   （2500万円 − 2060万円）× 1/2 = 220万円

3. 所得税額を計算（速算表より）
   220万円 × 10% − 9万7,500円 = 12万2,500円

このように、勤続年数が長いほど退職所得控除が大きくなり、課税対象が圧縮されます。
```

### 禁止事項

- 「節税効果が大きい」等の定性表現のみで数値の裏付けを欠く記述
- 計算結果のみを提示し過程を省略する記述
- 計算式に使った前提（年齢・年収・家族構成）を明示しない記述

## 4. ペルソナ別シミュレーション必須

### 標準ペルソナ（テーマに応じて3-4ケース選定）

| ペルソナID | 属性 | 想定年収 | 家族構成 | 主な悩み |
|-----------|------|---------|---------|---------|
| P-25S | 25歳独身 | 400万円 | 単身 | 老後資金の出発点設計 |
| P-30D | 30歳DINKs | 世帯900万円 | 配偶者あり子なし | 住宅取得タイミング |
| P-35F | 35歳子育て世代 | 600万円 | 配偶者+子1 | 教育資金と住宅の両立 |
| P-45F | 45歳教育費ピーク | 800万円 | 配偶者+子2 | 教育費捻出と老後設計 |
| P-55E | 55歳退職前 | 900万円 | 配偶者あり子独立 | 退職金運用と年金繰下げ |
| P-65R | 65歳退職直後 | 年金中心 | 配偶者あり | 取り崩し戦略と税負担 |
| P-40SP | 40歳シングルペアレント | 450万円 | 子1 | 公的保障と教育費 |

各ペルソナでは以下を必ず示す:

- 前提条件（年齢・年収・家族構成・既存資産）
- 計算式と計算過程
- 結論（数値）
- 結論の解釈と注意点

### 禁止事項

- 1ペルソナのみで結論を導出する記述
- ペルソナの前提条件を曖昧にしたシミュレーション
- 楽観シナリオのみを提示し悲観・標準シナリオを欠く記述

## 5. 業際規制への配慮

CFP級記事では、業際規制に該当する記述が増えるため特別な注意が必要。

### 業独占法令と対応パターン

| 法令 | 業独占範囲 | 記事での対応 |
|------|-----------|------------|
| 社会保険労務士法 第27条 | 個別の年金額・社保給付額の計算代行 | モデルケース計算に限定。「個別試算は年金事務所/社労士へ」明記 |
| 税理士法 第52条 | 個別税額の計算・申告書作成 | 一般論と仮定値モデルに限定。「個別申告は税理士へ」明記 |
| 保険業法 第275条 | 保険契約の募集（契約締結の勧誘） | 公的保障と保険要否の判断軸提示に留め、特定商品推奨を避ける |
| 金融商品取引法 第28条・第29条 | 個別銘柄・ファンドの投資助言 | 「〜という特徴を持つ商品群がある」「一例として〜」表現 |
| 宅地建物取引業法 第3条 | 不動産取引の媒介・代理 | 制度解説と一般論に留める |

### 必須の注記文

各カテゴリに該当するテーマでは記事末尾に以下を必ず挿入する。

```markdown
本記事は一般的な制度解説を目的としており、個別の年金額・税額・保険判断について助言・代理を行うものではありません。
個別のご事情に基づく試算・判断は、以下の窓口へお問い合わせください。

- 公的年金: お近くの年金事務所、または社会保険労務士
- 税務: 所轄税務署、または税理士
- 保険: ご加入先の保険会社、または保険代理店
- 投資: 金融商品取引業者（証券会社・銀行等）
```

## 6. 出典の埋め込みルール

### 引用ルール

- 数値・統計データには **必ず一次出典 URL** をマークダウンリンクで埋め込む
- 法令・通達は条文番号を明記し、e-Gov 法令検索等の公式URLにリンク
- 統計の引用には **発表日・対象期間** を併記

### 引用形式

```markdown
<!-- 推奨: 文中リンク + 発表日 -->
2026年4月時点で国民年金保険料は[月額17,510円](https://www.nenkin.go.jp/...)です（日本年金機構, 2026年4月発表）。

<!-- 推奨: 法令リンク -->
退職所得控除は[所得税法第30条](https://elaws.e-gov.go.jp/...)で規定されています。

<!-- 推奨: 統計の出典明示 -->
40代の世帯平均貯蓄額は1,250万円です（[家計の金融行動に関する世論調査](https://www.shiruporuto.jp/...) 金融広報中央委員会 2025年版）。
```

## 7. 図表の必須要件

CFP級記事では以下を必須化する。

### 図表数の最低基準

- **最低5枚**（standard の3-5枚から増加）
- うち1枚以上は計算式の可視化（フロー図・段階計算表）
- うち2枚以上はペルソナ比較（表 or 並列グラフ）

### 推奨される図表

| データ種類 | 図表種別 | 生成スキル |
|-----------|---------|-----------|
| 制度の全体像 | フロー図 | `/generate-concept-image` |
| 計算過程 | 段階計算表 | `/generate-table-image` |
| ペルソナ比較 | マトリクス / 並列棒グラフ | `/generate-table-image` または `/generate-chart-image` |
| 改正履歴 | 年表 | `/generate-table-image` |
| 給付額シミュレーション | 折れ線グラフ | `/generate-chart-image` |

## 8. 品質チェックリスト（CFP級専用）

### 構造
- [ ] 必須9セクションが揃っている
- [ ] 文字数が12000-15000字
- [ ] 1500字以上連続するセクションに最低1枚図表

### 計算
- [ ] 全ての数値に計算式が明示されている
- [ ] 計算過程に使った前提（年齢・年収・家族構成）が明記されている
- [ ] ペルソナ3-4ケースで結論が導出されている

### 出典
- [ ] 一次出典（ランクS）が50%以上
- [ ] 全ての統計に発表日と対象期間が併記されている
- [ ] 法令引用に条文番号がある
- [ ] 引用URLが本文中にマークダウンリンクで埋め込まれている

### コンプライアンス
- [ ] 業独占法令に抵触する個別計算がない
- [ ] 業際規制の注記文が末尾に挿入されている
- [ ] 特定商品の推奨表現がない
- [ ] 投資助言・税務代理・保険募集に該当する表現がない

### 図表
- [ ] 図表が5枚以上含まれている
- [ ] 計算式可視化が1枚以上ある
- [ ] ペルソナ比較が2枚以上ある
