# life_planning（ライフプランニング・資金計画）

CFP6分野のうち「ライフプランニングと資金計画」を中心に、社会保険・住宅・教育・退職設計を扱う。
将来 IFA として独立し顧客獲得につなげるための、CFP相当の専門品質コンテンツを制作する。

## 適用ルールの優先順位

このカテゴリは以下を組み合わせて適用する:

1. `common-rules.md` — 共通禁止表現・タイトル生成
2. `cfp-grade-rules.md` — CFP級の信頼性・計算式・ペルソナ要件（`quality_tier: cfp_grade` 時）
3. このファイル（`life-planning.md`）— カテゴリ固有の執筆ポイント
4. `.claude/rules/article-quality-standards.md` — 表/チャート画像化

> `quality_tier` のデフォルトは **cfp_grade**。明示的に `standard` を指定した場合のみ standard ルールを適用する。

## 対象読者

- **既定**: 投資・資産形成にある程度触れた **中級者以上**（FP3級レベルの基礎は既知）
- standard を選択した場合のみ初心者向け

CFP級記事は「資産運用の知識はあるが、年金・社保・税・保険の体系的整理ができていない読者」を想定する。
専門用語の平易化は必要だが、過度に基礎へ戻らず構造的な理解を優先する。

### テーマ別の執筆ポイント

#### pension（公的年金）

- 必ず国民年金 → 厚生年金 → 第3号 の順で 3階層を解説する
- 受給額は**令和7年度の改定後額**を基準値とする（毎年度4月改定）
- 繰上げ・繰下げの増減率は具体的な計算式で示す（繰上げ▲0.4%/月、繰下げ+0.7%/月）
- 在職老齢年金の支給停止調整額（48万円基準）は最新改定値を確認
- **業際注意**: 個別年金額の確定試算はNG。「ねんきんネット」「年金事務所」への誘導を必須

#### social_insurance（社会保険）

- 健康保険組合・協会けんぽ・国民健康保険の差異を構造的に説明
- 標準報酬月額の計算過程を必ず明示
- 高額療養費の自己負担限度額は所得区分別に提示
- 傷病手当金・出産手当金の支給期間と算定式
- **業際注意**: 個別給付額計算は社労士独占に該当。モデルケース表記必須

#### housing_loan（住宅ローン）

- 変動・固定・フラット35の3類型を金利推移と合わせて解説
- 住宅ローン控除は**2026年度（令和8年度）税制改正反映**で執筆
- 借換・繰上返済の損益分岐点を計算式で示す
- 団信（一般・がん・三大疾病）の保障範囲と保険料相当負担の比較
- **業際注意**: 「どの銀行のローンが良い」断定はNG。比較は構造論で示す

#### education_fund（教育資金）

- 幼稚園～大学までの学費総額を公的・私立別に提示（文科省学校基本調査）
- 学資保険・新NISA成長投資枠・教育資金一括贈与の3手法を比較
- 奨学金（JASSO第一種・第二種・給付型）の最新採用基準
- 教育資金一括贈与の特例：1500万円非課税枠（2026年改正）
- **業際注意**: 商品比較で特定保険会社の推奨はNG

#### retirement_design（リタイアメント設計）

- 退職所得控除の計算式と勤続年数別シミュレーション
- 4%ルールの日本での適用妥当性を実データで検証
- 公的年金等控除の年齢区分（65歳未満/以上）を明示
- 年金繰下げ受給と退職所得・iDeCo一時金受取の課税最適化
- **業際注意**: 個別税額計算は税理士独占。仮定値モデルに限定

#### life_event_planning（ライフイベント設計）

- 結婚・出産・住宅取得・教育費・介護・退職を時系列で配置するキャッシュフロー表
- 育児休業給付金の支給率（67%→50%、2025年改正）と上限額
- 介護休業給付金（67%、最大93日）と介護離職の経済影響
- 出産育児一時金（50万円）と直接支払制度
- **業際注意**: 個別CF表作成は「FP相談を」と案内

#### insurance_basics（保険基礎）

- 公的保障（健保・遺族年金・障害年金）でカバーされる範囲を先に提示
- 公的保障の不足分を見極めるフレームワーク（必要保障額の計算）
- 生命保険・医療保険・がん保険・就業不能保険の機能整理
- ライフステージ別の保険要否判断軸
- **業際注意**: 保険業法第275条への抵触回避が最重要。特定商品名・保険会社名を挙げての推奨は禁止。「〜という保障特性を持つ商品群がある」表現に統一

### 業際規制（必須遵守）

`data/config/life-planning-themes.json` の `regulatory_framework` セクションを参照。
記事中で抵触リスクのある表現を検出した場合は以下に置換する:

| 抵触リスク表現 | 安全表現 |
|--------------|--------|
| 「あなたの年金額は◯◯円です」 | 「同条件のモデルケースでは◯◯円となります」 |
| 「あなたの所得税は◯◯円減ります」 | 「年収500万円・40歳の場合は所得税◯◯円の節税となります」 |
| 「この保険商品がおすすめ」 | 「就業不能リスクを公的保障で補えない場合、就業不能保険という選択肢があります」 |
| 「◯◯銀行の住宅ローンが最有力」 | 「変動金利型かつ団信保障が手厚い商品群を比較検討する余地があります」 |

### 必須注記文

CFP級記事の末尾には、`cfp-grade-rules.md` § 5 の「必須の注記文」を必ず挿入する。
テーマに応じて該当する相談先を強調する:

- pension/social_insurance/retirement_design → 年金事務所/社労士を強調
- housing_loan/retirement_design → 税理士を強調
- insurance_basics/education_fund（学資保険） → 保険会社/代理店を強調
- 全テーマ共通 → FP・各専門家への相談導線

### 専門用語の平易化

CFP級記事でも、以下の用語は初出時に必ず平易化する:

| 専門用語 | 平易化例 |
|---------|--------|
| 標準報酬月額 | 健康保険・厚生年金の保険料を計算する基準となる、月収を等級に当てはめた額 |
| 加給年金 | 厚生年金の上乗せ給付。配偶者や子がいる受給者に支給される |
| 在職老齢年金 | 働きながら厚生年金を受給する場合に、給与額に応じて支給が調整される仕組み |
| 退職所得控除 | 退職金を受け取る際、勤続年数に応じて課税対象から差し引かれる控除額 |
| 公的年金等控除 | 公的年金等の収入から差し引かれる所得控除 |
| 高額療養費 | 1ヶ月の医療費自己負担が一定額を超えた場合に超過分が払い戻される制度 |
| 傷病手当金 | 業務外のケガ・病気で働けなくなった際、健康保険から支給される所得補填 |
| 団信（団体信用生命保険） | 住宅ローン契約者が死亡・高度障害になった際、残債が保険で完済される仕組み |
| ペアローン | 夫婦それぞれが住宅ローンを契約し、互いに連帯保証人となる方式 |
| 住宅ローン控除 | 住宅取得後一定期間、ローン残高に応じて所得税・住民税が控除される制度 |
| 暦年贈与 | 1月1日から12月31日までの1年間の贈与に対して課税する贈与税の計算方式 |
| 生命保険料控除 | 生命保険料の支払いに応じて所得税・住民税の課税所得から差し引かれる控除 |
