# asset_management（資産形成）

## 文字数

- **目標**: 8000-10000字
- **最低**: 8000字（これ未満は不可）
- **最大**: 10000字（これ超過は不可）

> common-rules.md の「適正な記事全体の長さ 3000-5000字」はこのカテゴリでは適用しない。
> 資産形成記事は初心者が一記事で体系的に理解できるよう、十分なボリュームで解説する。

## 対象読者

投資初心者（資産形成に興味はあるが経験が浅い層）。専門用語は初出時に必ず平易な説明を付ける（common-rules.md の専門用語平易化ルール参照）。

## セクション構成テンプレート

8000-10000字を以下の構成で配分する。各セクションの文字数目安は合計で8000-10000字になるよう調整すること。

```markdown
# {タイトル}

# はじめに
[400-600字: この記事で学べること、対象読者を明示、読者の悩み・疑問への共感]

# 基礎知識
[1500-2000字: 制度・概念の定義と仕組み、歴史的背景、重要性の解説]

# データで見る現状
[1000-1500字: 最新の統計データ・市場データを用いた現状分析、チャート・表を活用]

# 実践ガイド
[2000-2500字: ステップバイステップの解説、具体的な数値例（月3万円の積立など）、FAQ]

# ケーススタディ
[800-1200字: 具体的なシナリオや事例、年齢・収入別のモデルケース]

# 注意点・リスク
[800-1200字: よくある間違い、注意すべきリスク、初心者が陥りやすい罠]

# まとめ
[400-600字: 要点整理、今日からできるアクション、次のステップ]

---

## 参考データソース
{金融庁、証券会社公式、モーニングスター等}

免責事項: 本記事は一般的な情報提供を目的としており...（snippets/disclaimer.md の全文）
```

### セクション設計の注意点

- **「データで見る現状」と「ケーススタディ」が新設セクション**。8000-10000字の長尺フォーマットを活かし、データの可視化と具体例で読者の理解を深める
- セクション順序は固定。テーマによって「ケーススタディ」を「シミュレーション」に読み替えてよい
- 見出し間隔は 300-500字ごとにサブ見出し（##）を配置し、スマホでの読みやすさを維持
- テキスト 1500字以上のセクションには最低1枚の図表（表画像 or チャート画像）を挿入する

## テーマ一覧

記事は以下の6テーマに分類される。meta.yaml の `theme` フィールドに設定する。

| テーマキー | 日本語名 | キーワード | 推奨RSSソース |
|-----------|---------|----------|-------------|
| nisa | NISA制度 | NISA, つみたて, 非課税, 積立投資 | fsa, morningstar_jp, emaxis |
| fund_selection | ファンド選び | インデックス, ファンド, 信託報酬, eMAXIS, オルカン | emaxis, morningstar_jp |
| asset_allocation | 資産配分 | 資産配分, ポートフォリオ, 分散投資, リバランス | daiwa, morningstar_jp |
| ideco | iDeCo・企業型DC | iDeCo, 確定拠出年金, DC, 節税 | fsa, morningstar_jp |
| market_basics | 市場の基礎知識 | 株式市場, 経済指標, 為替, 債券, 金利 | jpx, boj, daiwa |
| simulation | 資産形成シミュレーション | 複利, 積立, シミュレーション, 老後資金 | fsa, daiwa |

### テーマ別の執筆ポイント

**nisa**: 制度の仕組み → 投資枠の使い分け → 具体的な活用戦略。2026年税制改正やこどもNISA新設など最新情報を反映する。

**fund_selection**: ファンド比較の軸（コスト・リターン・純資産・運用方針）を明確にし、定量データで裏付ける。eMAXIS Slim、SBI・V、楽天・全世界など主要ファンドを網羅的に扱う。

**asset_allocation**: 年齢・リスク許容度別のモデルポートフォリオを提示。GPIFの運用配分を参考モデルとして活用する。リバランスの具体的な手順を示す。

**ideco**: 税効果シミュレーション（所得税+住民税の節税額）を具体的な年収帯で示す。加入資格・拠出限度額の正確な記載が必須。

**market_basics**: 難解な金融概念を日常の比喩で説明する。経済指標の読み方は「数字 → 意味 → 投資への影響」の3段階で解説する。

**simulation**: 複利の威力を長期チャートで可視化する。楽観・標準・悲観の3シナリオを並べて現実的な期待値を示す。

## カテゴリ固有ルール

### ソースキュレーション

記事執筆前に、リサーチで収集したソースに関連度スコア（0-100）を付与し、スコア50以上のソースのみ記事に使用する。

#### スコアリング基準

| 基準 | 配点 | 説明 |
|------|------|------|
| テーマ適合度 | 30点 | テーマのキーワード・概念との一致度 |
| 情報の信頼性 | 25点 | 公的機関 > 大手金融機関 > メディア > 個人 |
| 鮮度 | 20点 | 直近の情報ほど高スコア |
| 初心者理解度 | 15点 | 初心者が理解しやすい説明があるか |
| 独自性 | 10点 | 他ソースにない独自の視点・データ |

#### 信頼性ランク

| ランク | ソース例 |
|--------|---------|
| A（最高） | 金融庁、日銀、東証、GPIF、投資信託協会 |
| B（高） | 大和証券、モーニングスター、eMAXIS公式、三菱UFJアセット |
| C（中） | 主要メディア（日経、Bloomberg等） |
| D（参考） | 個人ブログ、SNS（検証必須） |

キュレーション結果は `02_draft/curated_sources.json` に保存する。

#### ソース戦略（8000-10000字向け）

長尺記事では最低8件以上のソースを使用する。信頼性ランクの構成目安:

| ランク | 推奨割合 | 目安件数 |
|--------|---------|---------|
| A | 30%以上 | 3件以上 |
| B | 30%以上 | 3件以上 |
| C | 20%以下 | 2件以下 |
| D | 10%以下 | 1件以下（必ず検証） |

### 禁止表現（asset_management 追加分）

common-rules.md の禁止表現に加え、以下も禁止:

| 禁止表現 | 代替表現 |
|---------|---------|
| おすすめ | 一つの選択肢として |
| 間違いない | 可能性が高いと考えられる |
| 損しない | リスクを抑えられる可能性がある |
| 最強の | 優れた特徴を持つ |
| 一番良い | 多くの投資家に選ばれている |
| 推奨 | 一つの選択肢 |

### 専門用語の平易化（必須）

資産形成カテゴリでは特に厳格に適用する。以下のパターンのいずれかで説明する:

1. **括弧書き**: 「インデックスファンド（市場全体の値動きに連動する投資信託）」
2. **直後の補足文**: 「リバランスを行います。リバランスとは、値動きによってずれた資産配分を元の比率に戻す作業のことです。」
3. **例示**: 「ドルコスト平均法、つまり毎月同じ金額を積み立てる方法」

2回目以降は説明不要。

#### よく使う専門用語と平易化例

| 専門用語 | 平易化例 |
|---------|---------|
| インデックスファンド | 市場全体の値動きに連動する投資信託 |
| 信託報酬 | 投資信託を保有している間にかかる運用コスト |
| 基準価額 | 投資信託1口あたりの値段 |
| ドルコスト平均法 | 毎月同じ金額を機械的に積み立てる方法 |
| リバランス | 値動きでずれた資産配分を元の比率に戻す作業 |
| アセットアロケーション | どの資産にどれくらいの割合で投資するかの配分計画 |
| CAPE比率 | 過去10年の利益で計算した割高・割安の指標 |
| シャープレシオ | リスクに対してどれだけのリターンを得たかを示す効率性の指標 |
| 繰上償還 | 運用会社が予定より早くファンドを終了させること |
| 為替ヘッジ | 外国の資産に投資するとき、為替変動の影響を抑える仕組み |

### データの可視化戦略

8000-10000字の長尺記事では、読者の離脱を防ぐために積極的に図表を活用する。

#### 推奨される図表の種類

| データの種類 | 推奨図表 | 生成スキル |
|------------|---------|-----------|
| 純資産総額・リターンの推移 | 折れ線グラフ | `/generate-chart-image` |
| ファンド比較（コスト・リターン） | 比較表（画像） | `/generate-table-image` |
| 資産配分 | 円グラフ or 横棒グラフ | `/generate-chart-image` |
| シミュレーション結果 | 折れ線グラフ（3シナリオ） | `/generate-chart-image` |
| 制度比較（NISA vs iDeCo） | 比較表（画像） | `/generate-table-image` |
| 手数料・コスト一覧 | テーブル（画像） | `/generate-table-image` |

#### 配置目安

- 記事全体で **3-5枚** の図表を目標とする
- テキスト 1500字以上連続するセクションには最低1枚挿入
- 「データで見る現状」セクションには必ず1枚以上のチャートを含める
- 「ケーススタディ」セクションには表またはチャートで定量的なイメージを提供
