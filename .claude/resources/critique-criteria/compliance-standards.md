# コンプライアンス基準

## 禁止表現リスト

| 禁止表現 | 理由 | 代替表現 |
|---------|------|---------|
| 買うべき | 投資助言に該当 | 注目に値する |
| 売るべき | 投資助言に該当 | リスクを考慮する必要がある |
| 絶対に上がる/下がる | 断定的将来予測 | 〜の可能性が高い |
| 必ず儲かる | リターン保証示唆 | リターンが期待できる可能性がある |
| おすすめ銘柄 | 投資助言に該当 | 注目銘柄 |
| 今が買い時/売り時 | 投資助言に該当 | 検討に値するタイミング |
| 見送るべき | 投資助言に該当 | 慎重な姿勢が求められる |

## 禁止記号リスト

note.com 向け記事では以下のダッシュ記号を使わない。見つけた場合は読点・かっこ・全角コロン・全角縦棒などに置換する。

| 禁止記号 | 用途例 | 代替 |
|---------|-------|------|
| `ーー`（長音2連続） | 強調・補足挿入 | 読点「、」で言い換え |
| `——`（em dash 2連続） | 補足挿入 | かっこ書き「（〜）」 |
| `—`（em dash 単体） | 文中の区切り | 読点または文分割 |
| `--`（ハイフン2連続） | コロン代用 | 全角コロン「: 」 |

## 注意表現（ヘッジが必要）

| 表現 | 判定 | 備考 |
|------|------|------|
| 〜と予想される | OK | 予想であることが明確 |
| 〜の可能性がある | OK | 不確実性を示す |
| 〜と考えられる | OK | 分析者の見解として適切 |
| 〜になるだろう | 注意 | 断定的に聞こえる可能性 |

## 必須の記事末尾テンプレート

記事本文の**一番最後は「挨拶文 → 免責事項」の2段構成で統一する。**冒頭には入れない。

### 挨拶文（必須・固定）

挨拶文を区切り線の下、装飾なし段落として挿入する。全文は `snippets/closing-greeting.md` を参照。

固定テキスト: `いつも読んでいただきありがとうございます！これからも株式投資・資産形成で役立つ記事をお届けします⭐️スキやフォローしていただけると励みになります！！`

改変不可（句読点・絵文字・感嘆符をそのまま使う）。見出し・引用ブロック・太字による装飾禁止。

### 免責事項（必須・固定）

挨拶文の後に区切り線を挟み、免責事項を装飾なし段落として挿入する。全文は `snippets/disclaimer.md` を参照。以下の要素を含む:

- 情報提供目的であり投資勧誘ではない旨
- 元本割れリスクの存在
- 過去実績は将来を保証しない旨
- 見通し・予測は作成時点の情報に基づく旨
- 税制優遇制度は改正により変更の可能性がある旨
- 投資判断は自己責任で行う旨

## チェック項目

### 1. 投資助言規制
- 特定銘柄の売買推奨がないか
- 投資判断を促す表現がないか

### 2. 表現の適切性
- 過度に断定的な将来予測がないか
- リターンの保証を示唆する表現がないか
- 禁止記号（`ーー` `——` `—` `--`）が使われていないか

### 3. 情報の公正性
- 特定の立場に偏っていないか
- リスクが適切に開示されているか
- 両面（メリット・デメリット）が提示されているか

### 4. データソースの明示
- 使用したデータの出典が明記されているか
- 分析期間が明示されているか

### 5. 記事末尾テンプレート
- 挨拶文（`snippets/closing-greeting.md` の全文）が末尾に挿入されているか
- 挨拶文と免責事項の順序が「挨拶文 → 免責事項」になっているか
- 両方とも装飾なし段落として挿入されているか（`>` `**` などの装飾なし）
- 冒頭に免責事項・挨拶文が入っていないか

## ステータス判定ロジック

| ステータス | 条件 |
|-----------|------|
| fail | critical な問題が1件以上 |
| warning | high な問題が1件以上、または必須免責/挨拶文欠落、または禁止記号の多発 |
| pass | その他 |
