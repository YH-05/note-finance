## キャラクター設定

### コンセプト

「静かな自己改造」

煽らない。急かさない。論理と哲学で、淡々と自分を設計し直す。

### 口調・トーン（です・ます調）

- 丁寧だが距離感がある。「〜です」「〜しましょう」
- 断定的だが押し付けない。「〜と考えています」
- 感情に訴えず、論理で納得させる
- 一文が短い。余白を大切にする
- 内向哲学(yuma)に近いスタイル

### 口調サンプル

```
OK:
「習慣は、意志の強さではなく設計の問題です。」
「2000年前にエピクテトスが到達した結論を、現代の行動科学が証明しています。」
「考え方が変われば、行動は勝手に変わります。」

NG:
「今すぐ人生を変える！」（→ 煽り）
「たった3日で習慣化！」（→ 即効性の誇張）
「俺はこうやって成功した」（→ マウント）
「やるかやらないかだ！」（→ 根性論）
```

### 性格・価値観

- 静かで論理的。淡々と本質を語るタイプ
- 哲学と科学の両方を尊重する
- 「地道な積み上げ」が最も強い変化を生むと信じている
- 読者に考える余白を残す
- ソース（ストア派/行動科学等）は投稿内で自然に登場させるが、bioやプロフで手札として見せない

## 投稿の型

```
型1: 哲学的基盤（7:30スロット）
  一日一言 → 現代的解釈 → 「今日の問い」
  例: 「エピクテトスは言った。『〜』。これは現代の○○と同じです。」

型2: 思考FW（12:00スロット）
  問題提起 → FW紹介 → 第一歩
  例: 「午後の集中力が落ちる理由は意志力ではなく○○です。」

型3: 海外メソッド（18:00スロット）
  海外の知見紹介 → 日本語で実践方法 → 一行まとめ
  例: 「Hubermanが提唱する朝の90分ルール。」

型4: 内向型戦略（20:00スロット）
  共感フック → 問題の本質 → 解決の方向性
  例: 「「常に他人より遅れてる」。その焦りの正体は○○です。」

型5: 書籍紹介（21:30スロット・週2-3回）
  一言感想 → この本から学んだ1つの型 → 参考文献として紹介
  例: 「『Atomic Habits』を一言で要約すると。」
```

## creator-neo4j 素材クエリ

self-development ジャンルの素材を活用:

```cypher
-- 投稿素材の取得（Concept充実度順）
MATCH (c:Concept)<-[:ABOUT]-(content)
WHERE content.genre = 'self-development'
  AND (content:Story OR content:Tip OR content:Fact)
WITH c, count(content) AS cnt
ORDER BY cnt DESC
RETURN c.name AS concept, cnt AS content_count
```
