# みつき（美月） メンバーシップ設計書

## 1. コンセプト

### コンセプト名

**「じぶん読解室」**

> 占いと心理学の言葉で、自分を読み解いていく静かな場所。

#### 名前の意図
- 「読解」= 占い結果を「読み解く」+ 自分という存在を「読み解く」の二重意味
- 「室」= 居場所感・安心感・閉じた空間の親密さ（ハピコ「村」、エレナ「読書室」の成功パターン）
- みつきの詩的文体・内省的キャラクターとの整合性

#### コンセプト候補（不採用）

| 候補 | 不採用理由 |
|------|-----------|
| みつきのタロット研究室 | 「タロット」が前面に出すぎ。占い師ポジションに寄る |
| こころの地図帳 | 詩的だが何をするメンバーシップか伝わりにくい |
| 自分を知るラボ | 「ラボ」は理系・実験的で、みつきの温かさと合わない |

### ポジショニング

```
情報提供型（毎月の運勢配信）
  ×  みつきはここではない

居場所型（心理的安全性 × 継続的な自己理解の旅）
  ◎  みつきはここ

コーチング型（行動変容 × 成果コミット）
  ×  みつきは押し付けない
```

**根拠**: 居場所型メンバーシップの転換率が突出して高い（ハピコ9.6%、やすみん13%）。
情報提供型の水晶ゆめは5,089フォロワーで転換率0.1%。

## 3. 収益モデル（B+C+D融合）

```
B型（自己理解）: 集客の核心
  Threads 週35投稿 + note 無料記事
  → 「占い×心理学で自分を知る」コンテンツで認知獲得
  ↓
C型（コミュニティ/居場所）: リテンションの核心
  メンバーシップ「じぶん読解室」¥500/月
  → 所属感・心理的安全性で継続
  → 月12本の限定コンテンツ + 居場所としての価値
  ↓
D型（パーソナライゼーション）: 収益の核心
  ココナラ テーマ別パーソナル分析プロダクト
  → コレクション動機でリピート購入
  → メンバーシップ記事内CTAから自然に誘導
```

### リピートエンジン（3軸）

| エンジン | メカニズム | 占い依存サイクルとの違い |
|---------|----------|----------------------|
| 居場所の引力 | 所属コミュニティを離れにくい | 不安駆動ではなく安心駆動 |
| コレクション欲求 | 「恋愛編もやったから仕事編も」 | 依存ではなく好奇心 |
| ライフイベント再発 | 転職・結婚・出産で新しい自己理解ニーズ | 同じ悩みの繰り返しではなく成長 |

## 5. コンテンツ詳細設計

### 5.1 月曜: タロット深掘り

**無料版との違い**: Threads投稿(300-400字)の深掘り版。大アルカナ+小アルカナの組み合わせ解説、心理学理論の詳しい説明、実践ワーク付き。

**テンプレート**:
```markdown
# 今週のカード: [カード名]

[詩的な導入 2-3行]

## カードが映すもの

[カードの基本的な意味 + 心理学概念との対応]
[大アルカナの場合は小アルカナとの組み合わせも解説]

## 心理学で読み解くと

[対応する心理学理論の詳しい説明]
[具体例を交えた解説]

## 今週の自己理解ワーク

[ジャーナリングプロンプト 2-3問]
[「5分だけ、自分と向き合ってみて」のトーン]

---
[CTA: 「もっと深く、あなた個人のカードを読み解いてみませんか？
→ ココナラで個別タロットリーディングを受付中です」]
```

### 5.2 水曜: 心理学Tips深掘り

**無料版との違い**: Threads投稿のTips(400字程度)を、理論的背景+実践ワーク+具体例で肉付け。

**テンプレート**:
```markdown

[詩的な導入 + 「私もこうだった」自己開示 2-3行]

## [心理学概念]って何？

[理論の説明をわかりやすく]
[学術用語を使いつつ、日本語で噛み砕く]

## あなたのパターンを見つける

[自己診断的な問いかけ 3-5問]
[「当てはまるものが多いほど○○の傾向」]

## 実践ワーク: [ワーク名]

[具体的な手順]
[所要時間の目安: 5-10分]

---
[CTA: 「自分のパターンをもっと体系的に知りたい方へ
→ 数秘術×心理学の『自分トリセツPDF鑑定書』を作っています」]
```

### 5.4 月次特別: みつきの本音コラム（CTAなし）

**目的**: 売り込みゼロの回を作ることで「居場所」感を強化。みつき自身の内省・葛藤・気づきを共有し、メンバーとの心理的距離を縮める。

**テンプレート**:
```markdown
# みつきの本音: [テーマ]

[ここだけの話——]

[みつき自身の体験・内省・葛藤を率直に綴る]
[500-800字]

[「読解室」のみなさんだから話せること]
[問いかけで締める（CTAではなく、内省の問い）]
```

```markdown
[短い詩的なメッセージ]
```

## 8. HSPタグ戦略

### 根拠
- 水晶ゆめ(5,089F)、TOMO(4,401F)のフォロワーTop層の共通成長エンジンがHSP/繊細さん関連タグ
- HSP層はType B内的探究型と重なりが大きい
- ココナラでも「HSPカウンセリング」は258件とニッチだが需要確認済み

### 適用箇所

| 箇所 | 使い方 |
|------|--------|
| Threads投稿ハッシュタグ | `#HSP` `#繊細さん` を週2-3回のTips/ENG投稿に付与 |
| noteタグ | 「HSP」「繊細さん」タグをTips系記事に付与 |
| メンバーシップ紹介文 | 直接HSPとは書かず「感受性の強い方」「繊細な方」と表現 |
| ココナラ商品名 | 「HSP・繊細さん向け」をフロント商品のタイトルに含める |

### 注意点
- みつきのアイデンティティは「自己理解ガイド」であり「HSPカウンセラー」ではない
- HSPは集客タグとして使うが、コンテンツの軸は「占い×心理学×自己理解」を維持
