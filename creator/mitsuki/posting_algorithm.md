# みつき（美月） 投稿スケジューリングアルゴリズム

## 概要

**1日5投稿（Threads） + 1日1note** の半自動パイプライン。
7日サイクル制でカテゴリ比率を保証し、5スロットで投稿タイミングを管理する。

## 1. 日次スロット設計（5投稿/日）

| スロット | 時間 | カテゴリ | 狙い |
|---------|------|---------|------|
| S1 | 07:00 | タロット / 星座 | 朝のカードメッセージ・一日のテーマ設定 |
| S2 | 12:00 | 自己理解Tips | 昼の実践ワーク・気づきの入口 |
| S3 | 15:00 | エンゲージメント | 問いかけ・共感・コメント誘導 |
| S4 | 19:00 | 星座 / タロット（深掘り） | 夕方の深掘り・感情に寄り添う |
| S5 | 22:00 | note誘導 / Story（自己開示） | 夜の締め・note CTAまたは自己開示 |

## 2. 7日サイクル（35投稿/週）

### 2軸配分ルール

全投稿の70%を恋愛×愛着スタイル、30%を自己肯定感に配分する。

| 軸 | 配分 | 週あたり | 対象スロット |
|----|------|---------|------------|
| 恋愛×愛着スタイル | 70% | ~25本 | S1(恋愛タロット/星座), S2(恋愛Tips), S3(恋愛ENG), S4(恋愛深掘り) |
| 自己肯定感×占術 | 30% | ~10本 | S2(自己肯定Tips), S4(自己肯定星座), S5(Story) |

### 7日間のスロット配分

| 曜日 | S1(7:00) | S2(12:00) | S3(15:00) | S4(19:00) | S5(22:00) |
|------|----------|-----------|-----------|-----------|-----------|
| 月 | 恋愛タロット | 恋愛Tips（不安型） | 恋愛ENG | 恋愛星座 | note誘導 |
| 火 | 恋愛星座 | 自己肯定Tips | 恋愛ENG | 恋愛タロット深掘り | Story（自己開示） |
| 水 | 恋愛タロット | 恋愛Tips（回避型） | 恋愛ENG | 自己肯定星座 | note誘導 |
| 木 | 恋愛タロット | 恋愛Tips（パターン分析） | 恋愛ENG | 恋愛星座 | Story（自己開示） |
| 金 | 恋愛星座 | 自己肯定Tips | 恋愛ENG | 恋愛タロット深掘り | note誘導 |
| 土 | 恋愛タロット | 恋愛Tips（愛着×占術） | 恋愛ENG | 自己肯定星座 | Story（自己開示） |
| 日 | 自己肯定星座 | 自己肯定Tips | 恋愛ENG | 恋愛タロット | note誘導 |

カテゴリ比率（35投稿/週）:
- 恋愛タロット: 8本（23%）— S1×4 + S4×4
- 恋愛星座/自己肯定星座: 7本（20%）— S1×3 + S4×4（うち自己肯定3本）
- 恋愛Tips/自己肯定Tips: 7本（20%）— S2毎日（恋愛4本 + 自己肯定3本）
- 恋愛エンゲージメント: 7本（20%）— S3毎日
- note誘導: 3本（9%）— S5（月・水・金・日のうち3本）
- Story自己開示: 3本（9%）— S5（火・木・土）

**恋愛系合計**: ~25本（71%） / **自己肯定感系合計**: ~10本（29%）

## 3. note記事（6本/週）

### 記事構成（恋愛7:自己肯定感3 × 前半無料+後半有料モデル）

各記事 **5,000-6,000字**。前半~3,000字を無料公開、後半~3,000字をメンバーシップ限定/単品¥500で販売。
毎週1本のD型テーマ記事と金曜コラムは**完全無料**（サンプル）。

| 曜日 | テーマ | 軸 | 形式 | D型連動先 |
|------|--------|-----|------|----------|
| 月 | 恋愛×不安型愛着 | 恋愛 | 有料 or 完全無料（4週ローテ） | → 愛着スタイル恋愛分析 ¥1,500 |
| 火 | 恋愛×回避型愛着 | 恋愛 | 有料 or 完全無料（4週ローテ） | → 愛着スタイル恋愛分析 ¥1,500 |
| 水 | 恋愛×パートナーシップ | 恋愛 | 有料 or 完全無料（4週ローテ） | → パートナーシップ相性分析 ¥1,500 |
| 木 | 自己肯定感×数秘術 | 自己肯定感 | 有料 or 完全無料（4週ローテ） | → 本質・強み分析 ¥1,500 |
| 金 | みつきコラム | 混合 | **完全無料（毎週）** | ファン化促進 |
| 土 | 自己肯定感×星座 | 自己肯定感 | 前半無料+後半有料 | — |

完全無料サンプルの4週サイクル: 第1週=不安型愛着、第2週=回避型愛着、第3週=パートナーシップ、第4週=自己肯定感

毎週の内訳: 完全無料2本 + 前半無料+後半有料4本（恋愛系3本 + 自己肯定感系1本）

### 記事テンプレート（5,000-6,000字・ですます調）

```
【無料部分 ~3,000字】
1. 悩みフック導入（~500字）
2. 具体的なパターンの解説（~1,500字）
3. セルフチェック簡易版（~1,000字）

── この先はメンバーシップ「じぶん読解室」で読めます（単品 ¥500） ──

【有料部分 ~3,000字】
4. みつきの読み解き（~1,500字）
5. 実践ワーク + ココナラD型CTA（~1,500字）
```

### 文体ルール

- **ですます調で統一**（「〜ですよね」「〜かもしれません」「〜があります」）
- 詩的な冒頭フレーズ（体言止め・短文）は例外としてOK
- 心の声の引用（「嫌われたくない」等）は話し言葉のままでOK

### 心理学の扱い方ルール

- **学者名は出さない**（ボウルビィ、ユング、ベック等は使わない）
- **英語理論名は出さない**（Attachment Theory、CBT等は使わない）
- 「心理学の研究では〜」程度の引用にとどめる
- **具体的なパターン描写を優先**: 「このタイプの人はこうなりやすい → こうすると楽になります」
- 概念ラベル（安定型/不安型、認知の歪み等）は使ってOK
- 理論の説明より「読者が自分ごとに感じる」具体例・解決策を厚くする

### 3軸ローテーション（内容の多様性確保）

恋愛テーマで3軸を組み合わせ、豊富なパターンを確保:

**愛着スタイル軸**（週替わり）: 不安型 / 回避型 / 恐れ回避型 / 不安型×回避型の組み合わせ
**占い軸ローテ**（週替わり）: 第1週タロット / 第2週星座 / 第3週数秘 / 第4週総合テーマ
**切り口ローテ**: パターン解説型 / 悩み解決型 / セルフチェック型 / ワーク型

自己肯定感テーマ:
**心理学理論ローテ**（月替わり）: 愛着×自己価値 / 数秘術×本質発見 / 星座×強み / 認知パターン×自己肯定

### マガジン構成

4マガジン: 恋愛×愛着スタイル / 自己肯定感×占術 / パートナーシップ分析 / みつきコラム

### 旧設計（廃止）

~~note有料記事（数秘術鑑定書¥500-1,000、ガイドブック¥2,000-3,000、深掘り記事¥300-500）~~ → D型プロダクト（ココナラ¥1,500）に統合

## 5. テーマ選択アルゴリズム

### 5.1 タロットテーマ

大アルカナ22枚からランダム選択（重複排除付き）。

```python
MAJOR_ARCANA = [
    "愚者", "魔術師", "女教皇", "女帝", "皇帝",
    "教皇", "恋人", "戦車", "力", "隠者",
    "運命の輪", "正義", "吊るされた男", "死神", "節制",
    "悪魔", "塔", "星", "月", "太陽",
    "審判", "世界"
]

def select_tarot_card(state):
    recent = state["tarot_card_history"][-8:]  # 直近8枚を除外
    available = [c for c in MAJOR_ARCANA if c not in recent]
    return random.choice(available)
```

### 5.2 星座テーマ

エレメント順で巡回し、各エレメント内の3星座をローテーション。

```python
ELEMENTS = {
    "火": ["牡羊座", "獅子座", "射手座"],
    "地": ["牡牛座", "乙女座", "山羊座"],
    "風": ["双子座", "天秤座", "水瓶座"],
    "水": ["蟹座", "蠍座", "魚座"]
}
ELEMENT_ORDER = ["火", "地", "風", "水"]

def select_zodiac(state):
    idx = state["zodiac_rotation"]
    element = ELEMENT_ORDER[idx % 4]
    sign_idx = (idx // 4) % 3
    state["zodiac_rotation"] = idx + 1
    return ELEMENTS[element][sign_idx]
```

### 5.3 Tipsテーマ（恋愛×愛着スタイル + 自己肯定感）

テーマプールから均等分散 + 重み付き選択。恋愛系と自己肯定感系を7:3で混在。

**恋愛×愛着スタイル系（70%）**:

| ID | テーマ | キーワード | 重み |
|----|--------|-----------|------|
| RL1 | 不安型愛着の恋愛パターン | 追いかけ癖, 既読不安, 連絡頻度, 見捨てられ不安 | 1.5 |
| RL2 | 回避型愛着の恋愛パターン | 距離を置く, 親密さ回避, 自由が欲しい, 壁を作る | 1.5 |

```python
def select_tips_theme(state):
    recent = state["recent_themes"][-3:]
    available = [t for t in TIPS_THEMES if t["id"] not in recent]
    counts = state["theme_use_counts"]
    min_count = min(counts[t["id"]] for t in available)
    candidates = [t for t in available if counts[t["id"]] <= min_count + 1]
    weights = [t["weight"] for t in candidates]
    return random.choices(candidates, weights=weights, k=1)[0]
```

## 10. /mitsuki-draft の7日分生成フロー

`/mitsuki-draft` を1回実行すると、**7日分（35 Threads + 7 note = 42コンテンツ）** を一括生成する。

```
┌────────────────────────────────────────────────────────────┐
│ 1. posting_state.json 読み込み                               │
├────────────────────────────────────────────────────────────┤
│ 2. 7日分の全パラメータを一括決定（42コンテンツ分）             │
│    各日×5スロット → カテゴリ → 型 → テーマ → カード/星座     │
│    note記事テーマ（7本）も同時決定                            │
│    → 週間カレンダーをユーザーに提示（確認のみ、待たない）       │
├────────────────────────────────────────────────────────────┤
│ 3. 全投稿文を一括生成（mitsuki-writer スキル参照）            │
```
