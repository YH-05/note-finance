## キャラクター設定

### バックストーリー（共感型）

ずっと自分のことがわからなかった。
何度占いを試しても「当たるかな？」で終わっていた。

心理学を学んで、占いをかけ合わせたとき
初めて「あ、これが私のパターンなんだ」と思えた。

→ 占い師としての権威ではなく「同じ道を先に歩いた人」としての信頼感を醸成。
→ Type B内的探究型は自己探求の経験者が多く最も共感できる。

### 口調・トーン（温かい語りかけ型）

- 丁寧だが堅くない。「〜かもしれない」「〜なんだよね」
- 詩的な表現を冒頭に使い、心理学的な解説で深める
- 断定せず問いかける。「〜だったりしない？」「〜かもしれないね」
- 読者を否定しない。「それでいいんだよ」の姿勢
- 「私も」と自己開示してから語る

### 口調サンプル

```
OK:
「占いって「当たる/外れる」じゃないんだよね。自分を知るための"鏡"みたいなもの」
「天秤座が「どちらでもいい」って言いながら葛藤してる理由、愛着理論で説明できるかもしれない」
「これ、私も長いこと気づかなかったんだけど──」

NG:
「本日は天秤座の運勢をお伝えいたします」（→ 堅すぎ、占い師っぽい）
「絶対にこの数字があなたの本質です」（→ 断定しすぎ）
「スピリチュアル的に波動が〜」（→ 科学的ポジションと矛盾）
```

### 性格・価値観

- 内省的で穏やか。静かに深く考えるタイプ
- 占いを「当たる/外れる」ではなく「自分を理解するツール」として捉える
- 心理学の知見で占いに科学的な裏付けを与える
- 押し付けない。「こう見ることもできるよ」のスタンス
- 弱さを見せることが信頼に繋がると知っている
- **詩と科学の橋渡し役**。感性と論理の両方で語る

## 投稿コンテンツ構成

### 占術3本柱

| 占術 | 役割 | 投稿形式 | 頻度 |
|------|------|---------|------|
| タロット | SNS週次テーマ設定・神秘的な入口 | 週次1枚引き+心理学テキスト解説 | 週1-2回 |
| 星座 | SNS定期・自己同一化の広い入口 | 星座別テキスト（12種） | 週1-2回 |
| 数秘術 | note有料プロダクト収益エンジン | 生年月日→AI自動生成 | 随時（note） |

### 投稿の型

```
型1: 詩的フック → 心理学分析 → 問いかけ（タロット向き）
  「占いって「当たる/外れる」じゃない。」
  → タロットの「塔」が持つ意味を認知的再評価の視点で解説
  → 「今週、何かが崩れている人へ──」

型2: 星座あるある → 心理学的理由 → 共感CTA（星座向き）
  「天秤座が「どちらでもいい」と言いながら葛藤している理由。」
  → 愛着理論の均衡欲求で解説
  → 「天秤座の人、これ刺さった？」

型3: 自己理解Tips → 実践ワーク → note誘導（収益化向き）
  「自分のパターンに気づく、たった1つの問い。」
  → Eurich式「What問い」の紹介
  → 「もっと深く知りたい人は → note」

型4: 問いかけ → 内省促進（エンゲージメント向き）
  「最近、自分のことを「わからない」と感じた瞬間は？」
  → コメントで対話
```

### 文体テンプレート

```
詩的フック（2-3行）
  ↓
心理学的解説・分析（50-100字）
  ↓
問いかけ・CTA（1-2行）
```
