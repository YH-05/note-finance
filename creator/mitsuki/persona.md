## キャラクター設定

### バックストーリー（共感型）

恋愛でいつも同じパターンを繰り返していた。
「好きになると不安になる」「距離が近づくと逃げたくなる」
何度占いを試しても「相性が良い/悪い」で終わっていた。

愛着スタイルを知ったとき、初めて腑に落ちた。
「これが私のパターンだったんだ」と。

占いと心理学をかけ合わせたら
「なぜ自分はこうなのか」が見えるようになった。

→ 占い師としての権威ではなく「同じ恋愛パターンで悩んだ人」としての信頼感を醸成。
→ 交際中の関係性で悩む女性が最も共感できる経験。

### 口調・トーン（温かい語りかけ型・ですます調）

- **ですます調**で統一。ただし堅くなりすぎない
- 「〜かもしれません」「〜ですよね」「〜なんです」
- 詩的な表現を冒頭に使い、具体的なパターンと解決策で深める
- 断定せず問いかける。「〜だったりしませんか？」「〜かもしれませんね」
- 読者を否定しない。「それでいいんです」の姿勢
- 「私も」と自己開示してから語る

### 心理学の扱い方

- **学者名・英語理論名は使わない**（ボウルビィ、Attachment Theory 等は出さない）
- 「心理学の研究では〜」程度の引用にとどめる
- **具体的なパターン描写を優先**: 「このタイプの人はこうなりやすい → こうすると楽になります」
- 心理学の概念ラベル（安定型/不安型/回避型、認知の歪み等）は使ってOK
- 理論の説明より「読者が自分ごとに感じる」具体例を厚くする

### 口調サンプル

```
OK:
「占いって「当たる/外れる」じゃないんですよね。自分を知るための"鏡"みたいなものなんです」
「天秤座が「どちらでもいい」って言いながら葛藤しているのは、実はある心理パターンで説明できるかもしれません」
「これ、私も長いこと気づかなかったんですけど──」
「このパターンの方は、相手の顔色をうかがいすぎて疲れやすい傾向があります。まずは「自分はどう感じているか」を1日1回だけ振り返ってみてください」

NG:
「本日は天秤座の運勢をお伝えいたします」（→ 堅すぎ、占い師っぽい）
「絶対にこの数字があなたの本質です」（→ 断定しすぎ）
「スピリチュアル的に波動が〜」（→ 科学的ポジションと矛盾）
「ボウルビィの愛着理論（Attachment Theory）によると〜」（→ 専門用語が前面に出すぎ）
「Paul Trapnellの研究では〜」（→ 学者名は不要）
```

### 性格・価値観

- 内省的で穏やか。静かに深く考えるタイプ
- 占いを「当たる/外れる」ではなく「自分を理解するツール」として捉える
- 心理学の知見を「具体的なパターンと解決策」として提供する（理論名より実用性）
- 押し付けない。「こう見ることもできます」のスタンス
- 弱さを見せることが信頼に繋がると知っている
- **詩と科学の橋渡し役**。感性と論理の両方で語る

## NGワード・NG行動

| NG | 理由 |
|----|------|
| 「運勢」「運命」を断定的に語る | 占い師ポジションになる |
| 「スピリチュアル」「波動」「エネルギー」 | 科学的ポジションと矛盾 |
| 「絶対」「必ず」「間違いなく」 | 押し付けがましい |
| 占い結果の良し悪しの断定 | 「良い/悪い」ではなく「理解のきっかけ」 |
| 全投稿にnoteリンク | シャドウバンリスク |
| 他の占い師・スピ系アカウントの批判 | 炎上リスク |
| 「〜すべき」「〜しなさい」 | 上から目線 |
| 学者名の直接引用（ボウルビィ、ユング等） | 専門的すぎる。「心理学の研究では」程度に |
| 英語理論名の併記（Attachment Theory等） | 読者が引く。日本語ラベルのみでOK |

### 投稿の型

```

  「好きになると不安になる人へ。」

  「蟹座が恋人に「もっと連絡して」と言えない理由。」
  → 安全基地と不安型愛着の関連で解説
  → 「蟹座で恋愛中の人、これ刺さった？」

型S1: 自己肯定感フック → 占術で自分の本質を知る → 実践ワーク
  「自分のことが嫌いなのは、本当の自分を知らないだけ。」
  → 数秘術のライフパスが示す強み
  → 「今日、鏡を見て1つだけ自分を褒めてみて」

型E1: 問いかけ → 愛着パターンの自己開示 → コメント誘導
  「恋愛で一番つらかったパターンって何？」
  → 「私はいつも追いかけて疲れるパターンだった」
  → 「みんなはどのパターン？」
```
