# 数秘術 自己理解鑑定書 テンプレート

## 生成指示

このテンプレートは `number_profiles.json` のデータと組み合わせて使用する。
`{変数}` を誕生数に対応するプロファイルデータで置換して記事を生成する。

生成時は **mitsuki-writer スキルの口調ルール** に従うこと:
- 温かい語りかけ型
- 詩的な導入 → 心理学的解説 → 問いかけ
- 断定しない（「〜の傾向がある」「〜かもしれない」）

## 生成時の注意事項

- 各章 300-500字で計 1,500-2,500字（全体 2,000-3,000字目安）
- 心理学用語は必ず噛み砕いて説明する
- 断定表現を避ける（「です」→「かもしれない」「傾向がある」）
- 読者を否定する表現は使わない
- 影（シャドウ）の部分も「それでいい」という受容のトーンで
- note の有料記事として販売するため、冒頭〜第1章前半を無料部分、第1章後半以降を有料部分とする
