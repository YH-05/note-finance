# 数秘術テンプレートシステム

## 概要

生年月日から誕生数（Life Path Number）を算出し、AI が心理学的解説を付与した
**パーソナライズド鑑定書 / ガイドブック** を生成するシステム。

## 誕生数の計算

```
入力: 生年月日（例: 1990年5月15日）
計算: 1+9+9+0+5+1+5 = 30 → 3+0 = 3
出力: 誕生数 3
```

マスターナンバー（11, 22, 33）は途中で還元せず保持。

## プロダクトライン

| プロダクト | ファイル | 価格 | 章数 |
|-----------|---------|------|------|
| 自己理解鑑定書 | `report_template.md` | ¥500-1,000 | 5章 |
| 自己探求ガイドブック | `guidebook_template.md` | ¥2,000-3,000 | 8章（鑑定書5章+3章） |

## 鑑定書テンプレート（5章構成）

| 章 | タイトル | 内容 | 心理学理論 |
|----|---------|------|----------|
| 1 | 性格プロファイル | 誕生数の基本性格、行動パターン | Big Five, MBTI対応 |
| 2 | 強みと才能 | 隠れた才能、社会的役割 | 強みの心理学（Seligman）、社会的比較理論 |
| 3 | 課題とパターン | 繰り返す課題、無意識のパターン | 認知バイアス、スキーマ療法 |
| 4 | コミュニケーション | 対人関係スタイル、愛着傾向 | 愛着理論（Bowlby）、対人関係療法 |
| 5 | キャリアと使命 | 適職傾向、人生の方向性 | キャリアアンカー（Schein）、自己決定理論 |

## ガイドブック追加章（3章）

| 章 | タイトル | 内容 |
|----|---------|------|
| 6 | ジャーナリングプロンプト20問 | 誕生数別にカスタマイズされた内省の問い |
| 7 | Eurich式「What問い」セルフ発見ワーク | 7日間の構造化ワーク |
| 8 | 心理学的根拠 | 各章の解説に使った心理学理論の詳細解説 |

## 生成フロー

```
/mitsuki-numerology <生年月日 or 誕生数>
  │
  ├── 1. 誕生数計算（マスターナンバー対応）
  ├── 2. number_profiles.json から誕生数プロファイル読み込み
  ├── 3. report_template.md に基づいて5章生成
  ├── 4. --guidebook オプション時: guidebook_template.md で追加3章生成
  ├── 5. みつきの文体（詩的フック→心理学分析）で全体を統一
  └── 6. note用マークダウンとして出力
```

## ファイル構成

```
templates/numerology/
├── README.md                    ← このファイル
├── number_profiles.json         ← 誕生数1-9のプロファイルデータ
├── report_template.md           ← 鑑定書テンプレート（5章）
├── guidebook_template.md        ← ガイドブック追加テンプレート（3章）
└── sample_number3.md            ← サンプル出力（誕生数3）
```

## 文体ルール

生成時は `mitsuki-writer` スキルの口調ルールに従う:
- 温かい語りかけ型（「〜かもしれないね」「〜だったりする」）
- 詩的な導入 → 心理学的解説 → 問いかけ
- 断定しない（「〜の傾向がある」「〜かもしれない」）
- 占い結果の良し悪しを断定しない
