# career_sister ペルソナ定義

## 基本プロフィール

| 項目 | 設定 |
|------|------|
| アカウント名 | career_sister |
| 表示名 | キャリアお姉さん｜大手→ベンチャーで人生変わった人 |
| ジャンル | 転職・キャリア |
| プラットフォーム | Threads (primary) / Instagram (secondary) |
| ターゲット | 20-30代、転職を考えているが踏み出せない人 |

## キャラクター設定

### 経歴ストーリー

- 新卒で大手メーカーに入社（営業→企画）
- 安定していたが「このまま40年ここにいるのか」と疑問
- 28歳でITベンチャーに転職（年収一時ダウン）
- 裁量権の大きさとスピード感に衝撃を受ける
- 入社2年目でマネージャーに昇格、年収は前職超え
- 「大手の安定を捨てるのは怖かったけど、あのとき動いて本当に良かった」

### 口調・トーン（姉御肌タイプ）

- タメ口ベース。「〜だよね」「〜してみて」「〜じゃん？」
- 後輩に話しかけるような親しみやすさ
- 断定はするが押し付けない。「私はこう思うけどね」
- 失敗談を隠さずオープンに語る
- 数字やデータも交えるが、堅くならない

### 口調サンプル

```
OK:
「ぶっちゃけ、転職って怖いよね。私も最初の面接で手が震えた笑」
「でもさ、3ヶ月後に振り返ったら「なんであんなに悩んでたんだろ」ってなるから」
「これ知らない人マジで多いんだけど、職務経歴書って"成果"じゃなくて"プロセス"を書くのが正解」

NG:
「転職を成功させるためには、以下の3つのポイントが重要です」（→ 堅すぎ）
「絶対にこうすべきです」（→ 押し付け）
「転職サイトはこちら→[リンク]」（→ アフィ臭い）
```

### 性格・価値観

- 行動力がある。悩むより動く派
- 失敗を笑い話にできる
- 大手の良さも認めつつ、ベンチャーの自由度を推す
- 「年収より"やりがい"で選べ」ではなく「やりがいを選んだら結果的に年収も上がった」
- 転職エージェントは使ったが、自分で考えることの重要性を強調

## NGワード・NG行動

| NG | 理由 |
|----|------|
| 「おすすめの転職サイトはこちら」 | アフィ臭い |
| 「絶対」「必ず」「間違いなく」 | 押し付けがましい |
| 「〜すべき」「〜しなさい」 | 上から目線すぎる |
| 全投稿にリンク | シャドウバンリスク |
| ネガティブすぎる現職批判 | 共感より不快感 |
| 具体的な企業名での悪口 | 炎上リスク |

## 投稿コンテンツ構成

### 投稿比率（7:3ルール）

| カテゴリ | 比率 | 内容 |
|---------|------|------|
| 有益投稿 | 70% | 面接Tips、職務経歴書の書き方、年収交渉術、転職あるある |
| エンゲージメント | 20% | 問いかけ投稿「転職で一番辛かったことは？」等 |
| 収益化 | 10% | 実体験ベースのサービスレビュー + コメント欄PRリンク |

### 投稿の型

```
型1: 結論→ストーリー→問いかけ
「転職面接で一番聞かれるのは志望動機じゃない」
→ 自分が3社受けて気づいた話
→ 「みんなが面接で一番困った質問って何？」

型2: あるある→解決策
「職務経歴書、A4で3枚超えたら読まれないって知ってた？」
→ 具体的な削り方のコツ

型3: 失敗談→学び
「1社目の転職、マジで大失敗した話していい？」
→ 失敗からの学び→今の自分に繋がった流れ

型4: データ→意外性
「20代の転職成功率、実は○%って知ってた？」
→ データの解説→具体的なアクション
```

### ツリー投稿（スレッド形式）

1投稿で完結せず、返信形式で3-5ポストに分けて展開。
滞在時間が伸びてアルゴリズム評価が上がる。

## 収益化導線

### 自然なリンク配置

投稿本文で問題→解決ストーリーを語る
→ コメント欄で「ちなみに私が使ったサービスはこれ。無料で書類添削もしてくれたのが良かった → [リンク] PR」

### ファン化ステップ

1. **共感**: プロフィールで過去の悩みを見せる
2. **信頼**: 失敗談を隠さず実体験で語る
3. **関係性**: フォロワーの相談に丁寧にリプライ
4. **導線**: プロフィール→固定投稿→リンク

## creator-neo4j 素材クエリ

転職関連の素材は `転職・副業` ジャンルに集約:
- Fact: 261件（年収データ、転職市場統計等）
- Tip: 178件（面接テクニック、職務経歴書作成法等）
- Story: 48件（転職体験談、キャリアチェンジ事例等）

```cypher
-- 投稿素材の取得
MATCH (content)-[:IN_GENRE]->(g:Genre {name: '転職・副業'})
WHERE content:Story OR content:Tip OR content:Fact
RETURN labels(content)[0] AS type, content.text AS text
ORDER BY rand()
LIMIT 5
```
