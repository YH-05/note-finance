## Post 2: 有益投稿（職務経歴書）

**カテゴリ**: 有益投稿（70%枠）
**型**: 結論→解決策
**素材**: creator-neo4j Tip / キャリアチェンジ年代別特徴

```
職務経歴書で一番やっちゃいけないこと教えるね。

「成果」だけ書くこと。

「売上120%達成」とか書いても、
正直、採用側は「で、何をしたの？」ってなる。

大事なのは"プロセス"なんだよね。

✅ どんな課題があって
✅ 何を考えて
✅ どう行動したか

私が大手→ベンチャーに転職したとき、
「メーカー営業の経験がITに活きるの？」って聞かれた。

そのとき書いたのは、
「顧客の声を起点にサービス改善を行ってきた経験」。

営業じゃなくて"課題解決のプロセス"として翻訳したの。
これがハマって、面接3社中2社から内定もらえた。

前職のスキルを新しい職種の言葉に"翻訳"する。
これが異業種転職の最大のコツだと思う。
```

## Post 4: 有益投稿（データ系）

**カテゴリ**: 有益投稿（70%枠）
**型**: データ→意外性
**素材**: creator-neo4j Fact / キャリアチェンジ年代別特徴、フリーランス年収データ

```
「30代で転職って遅いですか？」

この質問、めちゃくちゃ多い。
答えから言うと、全然遅くない。むしろ"武器が増えてる時期"。

20代はポテンシャル採用で可能性が広い。
でも30代は「即戦力」として見られる分、
"何を経験したか"で年収が決まる構造になってる。

つまり、大手で培ったマネジメント経験とか、
数字を読む力とか、
それって他の業界でもめちゃくちゃ欲しがられるスキルなの。

ポイントは「ポータブルスキル」の翻訳。

論理的思考力、傾聴力、交渉力、課題発見力…
これ、業界が変わっても使えるよね。

「今の会社でしか通用しないんじゃ…」って思ってる人、
それ、翻訳の仕方を知らないだけかもしれないよ。
```

## Post 5: 有益投稿（面接Tips）

**カテゴリ**: 有益投稿（70%枠）
**型**: あるある→解決策
**素材**: creator-neo4j Fact / 面接関連

```
転職面接で一番聞かれるのは志望動機じゃない。

「なぜ今の会社を辞めるんですか？」

これ、答え方で9割決まると思ってる。

❌ NG回答：
「人間関係が…」「残業が多くて…」「給料が低くて…」

気持ちはわかる。でもこれ言ったら
「うちでも同じこと言いそう」って思われて終了。

✅ OK回答の考え方：
「今の環境ではできないことがある」にフォーカスする。

私の場合はこう言った：
「大手で安定した基盤を学べたが、
もっと裁量を持って事業を動かしたい。
そのためにスピード感のある環境を選びたい」

ポイントは、
"逃げ"じゃなくて"攻め"の理由にすること。

今の会社の不満じゃなくて、
「次で何がしたいか」に変換する。

これだけで面接官の反応マジで変わるから、
騙されたと思って試してみて。
```
